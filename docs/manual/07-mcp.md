# 7. MCP：让 Claude Desktop 用 OneDesk

MCP 是让外部 AI 客户端（Claude Desktop、Claude Code 等）调用工具的协议。OneDesk 自带一个小程序 `onedesk-mcp`，让这些客户端**只读地**使用你**明确放开**的东西：找到保存的查询、看它要什么参数、用指定环境运行它、读结果。

这和第 6 章不同：第 6 章是 *OneDesk 去问* AI；这一章是 *AI 客户端来用* OneDesk。

## 安全模型（先看这个）

- **默认全关**：总开关关、资源对 AI 不可见、动作不可用。
- AI 只能**读**。内核拒绝它的一切写入、删除、安装、改设置、读密钥值。
- AI 只能看到你逐条标成“**对 AI 可见**”的资源，只能运行插件声明为“AI 可用且只读”的动作。
- AI **不能选环境**：它的运行都用你在“AI 运行用的环境”里指定的那一个。AI 看不到环境里的密钥值。
- 每次调用都写进审计（工具名、对象、结果行数、耗时、成败），审计页可按操作者“AI”过滤。**SQL 内容不进审计**。
- `onedesk-mcp` 只用标准输入输出和本机连接，**不开任何网络端口**。

## 第一步：在 OneDesk 里放开

### 1. 总开关与限额

右上角设置菜单（齿轮）→ **AI 访问**：

| 项 | 默认 | 说明 |
|---|---|---|
| 允许 AI 客户端 | **关** | 总开关；关着时所有 AI 请求都被拒绝 |
| 每分钟调用次数 | 30（1–600） | 整个工作区所有 AI 客户端**合计** |
| 每次结果的行数 | 200（1–2000） | 表格结果超过会被截断 |
| 允许自由查询 | **关** | 见下 |
| AI 运行用的环境 | 不使用环境 | AI 的运行都用它 |

页面底部会写“现在向 AI 客户端提供 N 个工具”。这几项就是工作区配置里的 `mcp.enabled`、`mcp.rate_per_minute`、`mcp.max_rows`、`mcp.allow_free_query`、`mcp.env`（统称 `mcp.policy`）。

### 2. 对 AI 可见

打开某条资源（例如一条保存的 SQL 或目录查询）→ 信息面板 → **对 AI 可见**，默认关。分组节点上有“对 AI 可见（包括下面的全部内容）”，一次放开整组。**没打开的资源，AI 搜不到、也读不到。**

### 3. 自由查询（默认关）

打开“允许自由查询”后，AI 才多一个工具 `run_sql`：自己写一条 `SELECT`/`WITH` 跑在映射过的表上。仍然只读执行（只读事务、超时、行数上限），并拒绝多条语句和一批危险函数（如 `pg_terminate_backend`、`dblink*`、`pg_read_file`、`lo_*`）。但黑名单挡不住所有可能，**根本的保护是用只读的数据库账号**。不需要就别开。

## 第二步：在 Claude Desktop 里配置

“AI 访问”页的“在 Claude Desktop 中使用”区会显示 `onedesk-mcp` 的路径和一段可复制的配置。它也可以在终端里生成：

```bash
/path/to/onedesk-mcp --print-config
```

输出长这样（`command` 是这个程序的实际路径）：

```json
{
  "mcpServers": {
    "onedesk": {
      "command": "/path/to/onedesk-mcp"
    }
  }
}
```

做法：

1. 打开 Claude Desktop → 设置 → 开发者 → **编辑配置**，打开 `claude_desktop_config.json`。
2. 把上面的 `onedesk` 条目**合并**进 `mcpServers`（不要覆盖你已有的其他服务）。
3. **重启 Claude Desktop**。

**程序在哪**：在 `OneDesk.app` 里面。确切路径以“AI 访问”页显示的为准（页面也有“复制路径”按钮）。如果页面提示“程序还不在这个位置”，说明应用没装好，重新安装。（实际位置是 `OneDesk.app/Contents/MacOS/onedesk-mcp`，与主程序同一目录。）

**多个工作区**：默认用应用打开的那个默认工作区。要指定别的：加参数 `--workspace <编号/名字/文件夹>`，例如

```json
{
  "mcpServers": {
    "onedesk-work": {
      "command": "/path/to/onedesk-mcp",
      "args": ["--workspace", "work"]
    }
  }
}
```

要用多个工作区，就在配置里写多条。`--print-config --workspace work` 会直接生成这样的条目。

**应用开着或没开都能用**：应用开着时它连到应用；没开时它自己临时启动一个无界面的后台进程，用完退出。AI 正在用时你打开应用，应用可能要等它释放（最多等一小会儿）。

## AI 能用哪些工具

| 工具 | 做什么 |
|---|---|
| `search` | 按文字找对 AI 可见的资源（只给名字、说明、标签，不给正文） |
| `describe` | 看一条资源的说明和参数（名字、类型、必填、可选值） |
| `run` | 用“AI 运行用的环境”运行一条资源，给参数，取回结果（表格或文字，按行数上限截断） |
| `get_run` | 读一次运行的结果（长结果分页）；只能读自己发起的运行 |
| `list_tables` | 列出映射过的表和字段（表插件提供） |
| `run_sql` | 自由查询；**只有打开“允许自由查询”才出现** |

常见被拒绝的情形（界面里的原因文字）：“这个工作区已关闭 AI 访问”（总开关没开）、“这个动作不对 AI 客户端开放”、“这个 AI 客户端调用太频繁”、“已对 AI 客户端关闭自由查询”、“为 AI 运行选择的环境已经不存在了”。

> 待确认：没有用真的 Claude Desktop 连过——验收只用了仓库里的假 MCP 客户端和 `--print-config` 的输出。第一次配置遇到问题请反馈。
>
> 待确认：带密码的数据源经 MCP 运行（无界面进程读钥匙串）没有在真钥匙串上验过；验收时用的是免密码的只读角色。建议给 AI 用的数据源配**免密码的只读角色**或确认能正常取到密钥。
