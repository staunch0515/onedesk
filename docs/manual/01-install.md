# 1. 安装与首次打开

## 系统要求

- macOS 11.3 或更新。同一个安装包同时支持 **Apple 芯片（M1/M2/…，如 iMac M1）** 和 **Intel 芯片（如 Mac Pro Intel）**。Windows 版暂不提供。
- 连 PostgreSQL、用 AI 时还需要别的东西，见各章（例如本机要有 `psql`）。

## 安装

1. 拿到 `OneDesk-<版本>-macos-universal.dmg`，双击打开，把 `OneDesk` 拖到旁边的“应用程序”图标上。（也提供同内容的 `.zip`：解压得到 `OneDesk.app`，拖进“应用程序”。）
2. 这个应用没有经过苹果公证，第一次打开要按下面的方式右键打开。

可以用发布目录里的 `SHA256SUMS` 核对文件：`shasum -a 256 -c SHA256SUMS`。

## 第一次打开：要在 Finder 里右键“打开”

这一版的 `.app` 只做了**本机自签名**，没有经过 Apple 公证（公司没有为它买开发者账号并送审）。所以 macOS 的 Gatekeeper 会在第一次双击时拦下它，提示“无法打开，因为无法验证开发者”之类。这不代表程序有问题，是 macOS 对没有公证的应用的统一做法。

做法：

1. 在 Finder 里打开“应用程序”，找到 OneDesk。
2. **按住 Control 点它（或右键）→ 选“打开”**。
3. 弹窗里再点一次“打开”。

只需要这一次；之后正常双击就行。

如果右键“打开”这条路走不通（比如较新的 macOS 弹窗里没有“打开”按钮），可以去“系统设置 → 隐私与安全性”里点“仍要打开”，或者在终端里去掉隔离标记：

```bash
xattr -dr com.apple.quarantine /Applications/OneDesk.app
```

之后正常双击。

## 首次启动会发生什么

- OneDesk 在你的资源库里创建**数据目录**（见[第 2 章](02-data-and-backup.md)）和一个名为“default”的工作区。
- 随应用带的内置插件被复制到数据目录里。
- 没有打开任何内容时，会显示“欢迎”页（内置的欢迎插件，只在没有标签时打开一次）：“新建笔记 / 新建网址 / 新建提示词”的入口。
- 应用只带最基础的插件（欢迎、笔记、网址、提示词、文件、综合、插件市场、AI 工作台与 Anthropic/Ollama 连接、简体中文）。其余功能（SQL、数据源、HTTP 请求、服务器命令、本机脚本、查询目录、表、集合、日语等）以插件包 `.odplugin` 提供，见下一节。
- 用到钥匙串（保存密码、API 密钥）时，macOS 可能弹出“OneDesk 想使用钥匙串”的询问，选“允许”。**待确认**：每次升级应用后是否会再次询问（应用是临时签名，换版本后系统可能认为它是另一个程序；需要真机升级一次才能确认）。

## 安装更多插件

发布目录的 `plugins/` 里是可选插件，每个是一个 `<插件 id>-<版本>.odplugin` 文件。两种装法：

- **插件市场**（推荐）：左侧“插件市场” → 工具栏“添加文件夹”授权一个放插件包的文件夹 → 把 `.odplugin` 文件放进这个文件夹（顶层）→ 在列表里选中，点“安装”，确认对话框里看清名称和权限后再确认。
- **命令**：命令面板（⌘K）→“安装插件…”→ 选 `.odplugin` 文件。

以后有新功能时，只要拿到新版本的 `.odplugin` 照样安装即可（版本号更高的包会接管旧版本的数据），不用重装应用。

## AI 辅助

在 AI 设置里配好 Anthropic 或 Ollama 连接后，页面上的文本字段旁会出现 ✨“用 AI 写”，有多个字段的页面有“用 AI 填写”。默认先显示将发送的内容，按“发送”才发；AI 的结果只是提议，按“接受”才放进页面（未保存）。

## 升级

直接用新的 `.app` 覆盖旧的。你的数据在数据目录里，不在 `.app` 里，不受影响。打开时如果数据库需要升级，OneDesk 会**先在工作区的 `backups/` 里留一份升级前的副本**再升级（见第 2 章）。

## 卸载

把 `.app` 拖进废纸篓即可。数据目录**不会**自动删除（你的数据还在）；不想要了再手动删。钥匙串里的条目也要自己在“钥匙串访问”里删。
