# 6. AI 设置（Anthropic 与 Ollama）

OneDesk 里的 AI 是三个插件配合：

- **AI 工作台**（`org.onedesk.ai`）：你看到的界面——“分析”按钮、预览、保存分析、“用 AI 写”SQL。它自己不连任何服务。
- **Anthropic（Claude）连接**（`org.onedesk.ai.anthropic`）：连 `api.anthropic.com`。
- **Ollama 连接**（`org.onedesk.ai.ollama`）：连你自己电脑（或你指定的服务器）上的 Ollama。

AI 工作台通过一个“默认 AI 连接”找到该用哪个服务。

## 一、建连接

“新建”菜单里选“Anthropic 连接”或“Ollama 连接”。可以建多个（例如“公司 Anthropic”“本机 Ollama”）。

### Anthropic 连接

| 字段 | 说明 |
|---|---|
| 地址 | 默认 `https://api.anthropic.com`。远程地址必须是 `https://`；只有本机地址才允许 `http://` |
| API 密钥 | **只写入钥匙串**，写完不再显示 |
| 模型 | 默认 `claude-haiku-5-5`；也可以填 `claude-sonnet-5-5`、`claude-opus-5-5` |
| 档位 | 低 / 中 / 高，默认中 |
| 最大输出 token | 默认 16000，最多 32000 |
| 回答被拒时改用备用模型 | 默认开；只对 Sonnet、Opus 有效，Haiku 没有 |

页面会写明“通过这个连接只能访问 api.anthropic.com”。点“测试连接”，成功会显示可用模型数。

### Ollama 连接

| 字段 | 说明 |
|---|---|
| 地址 | 默认 `http://127.0.0.1:11434` |
| 模型 | 你已下载的模型名，如 `llama3.1`。没下载过的会提示运行 `ollama pull <模型>` |
| 上下文长度（num_ctx） | 可选，留空用模型默认 |
| 模型常驻时间 | 默认 `5m` |
| 认证请求头名称 / 值 | 可选，只给放在反向代理后面的 Ollama 用；值只写入钥匙串 |

OneDesk **不下载、不删除**模型，用 Ollama 自己的命令。第一次调用要先把模型载入内存，可能要几十秒到几分钟，界面会显示“正在载入模型…”。

## 二、选默认连接

AI 工作台按这个顺序找连接，先找到的先用：

1. 分析页上手动选的“AI 连接”；
2. 当前环境里的参数 `ai.connection`；
3. 工作区配置里的 `ai.connection`；
4. “插件”里 AI 工作台的**设置项**“默认 AI 连接”（可选任何实现了 AI 对话的连接）。

都没有就提示“还没有设置 AI 连接”。这样“生产”环境可以用公司的连接，“个人”环境用本机 Ollama。

## 三、`ai.policy`：这个环境允不允许用 AI

这是**环境参数** `ai.policy`，三档：

| 值 | 含义 |
|---|---|
| `off` | 不许用 AI。点“分析”会提示被环境禁止，什么都不读取、不发送 |
| `preview` | 默认。必须先看预览再发送 |
| `allow` | “用 AI 写”这类**不带数据**的请求可以直接发；带数据的分析仍要预览 |

没设、或写了别的值，都当作 `preview`（不会比你要求的更宽松）。管理环境的人可以按环境设：例如生产环境 `off`。

> 这和第 7 章的 `mcp.*`（外部 AI 客户端怎么用 OneDesk）是两回事，别搞混。

## 四、分析流程与数据会发给谁

1. 在表格结果上点**分析**。
2. 先打开**预览页**：显示**将要发送的完整内容**（可以直接编辑）、用哪个连接和模型、大约多少 token；可勾选要不要附参考文档。
3. 按**发送**才会发出；之前什么都不会发。
4. 回答边生成边显示。想留下就点**保存分析**——它挂在那次运行下面；不保存就不留。

**数据发给谁**：只发给那个连接声明的主机——Anthropic 连接发给 `api.anthropic.com`；Ollama 连接发给你填的地址（通常是你自己的电脑，数据不出本机）。每个连接只能访问它自己声明的主机。

**发出去之前会处理**（预览里看得到处理后的样子）：

- 默认只带结果的**前 20 行**，每个单元格最多 200 个字符（两个数都能在 AI 工作台的设置项里改）；
- 名字像 `password`、`token`、`secret`、`email`、`phone` 的列整列打码，你还可以在 AI 工作台的设置项“更多敏感列名”里加；
- 邮箱和长数字串打码；
- 参考文档只带到预算内（默认约 3000 token）。

**密钥**：API 密钥只在钥匙串，插件、数据库、日志、导出文件里都没有明文。

**审计**：每次发送留一条记录——哪个连接和模型、发了多少字、用量；**不记内容本身**。

**AI 生成的 SQL**：只是提议，要你按“接受”；而且只允许单条 `SELECT`/`WITH`；运行时仍走原来的只读通道，不因为是 AI 写的就放宽。

## 五、费用提醒

- **Anthropic 是按用量收费的**（按输入和输出的 token），费用记在你填的 API 密钥所属的账户上，OneDesk 不会替你付，也不显示金额。每次回答后界面会显示用了多少输入/输出 token；价格请看 Anthropic 官网。
- 默认模型 `claude-haiku-5-5` 是三个里最便宜的；改成 Opus 会明显更贵。大结果、很多参考文档、档位调高，都会增加 token。
- 预览页的 token 数是**估算**；发送前先看一眼，尤其是勾了很多参考文档时。
- Ollama 在你自己机器上跑，不收 API 费用（只占用你电脑的算力）。
- 想控制花费：在 Anthropic 控制台给这个密钥设额度，并只给需要的人建连接。

## 六、参考文档（可选）

在“插件”里 AI 工作台的设置项“文档文件夹”中，填一个你**已授权**的文件夹设为“文档文件夹”，里面的 Markdown 和文本文件会成为参考文档；分析时按结果里的表名、列名挑相关的附上。
