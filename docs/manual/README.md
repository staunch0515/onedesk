# OneDesk 用户手册

给第一次用 OneDesk 的同事。不需要懂开发。版本 1.0（仅 macOS 11.3 及以上）。

OneDesk 是一个桌面工作台：左边是一棵树，放你的笔记、网址、提示词、保存的 SQL、数据源……每一类东西由“插件”提供。你在这里写的东西都存在你自己的电脑上。

## 界面一览

- **顶栏**：工作区、搜索（⌘K）、“新建”、设置。**底部状态栏**：工作区、环境、连接、任务、语言等。
- **最左的图标栏**：每个图标是一个视图（资源、环境、运行记录、插件……），点一下在旁边的侧栏显示它的树；最下面是设置。图标栏最上面的按钮把它**展开成宽面板**：所有视图以大图标 + 名称排成网格，上面有“查找视图”搜索框；再点一次收回成窄的一列。展开或收起会被记住。
- **侧栏**：视图标题（如“资源”），标题右边是这棵树自己的按钮（新建分组、全部展开、全部折叠等），下面是“按名称过滤”和树。
- **标签页**：每个打开的东西一个标签。标签下面两行：
  - 第一行是**位置**：所在的分组可以点，最后是当前名称（加粗），后面跟着类型、状态、“未保存”等标记；
  - 第二行最左是**环境选择**（用到环境的页面才有），细线后面是执行、保存等按钮，多于 4 个的在“…”里；这一行最右边是**信息面板**的开关。
- **信息面板**：窗口宽（1600 像素及以上）时在内容左边、靠近树；窄一些时在内容右边，窗口拉宽或缩窄时自动换边。可以收起、拖动改宽度，宽度会被记住。
