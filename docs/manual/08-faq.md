# 8. 常见问题

**双击打不开，提示无法验证开发者。**
见[第 1 章](01-install.md)：第一次要在 Finder 里右键（或按住 Control 点）→“打开”。

**我的数据在哪？怎么备份？**
`~/Library/Application Support/onedesk/`。见[第 2 章](02-data-and-backup.md)。

**界面上说“工作区服务已停止，正在重启…”。**
OneDesk 把工作区放在一个单独的后台进程里；它出问题时会自动重启，通常几秒内恢复，提示变为“工作区服务已恢复”。正在进行的运行会被中断（记录里写“工作区服务重启，这次运行被中断”）。如果反复出现，把数据目录里工作区的 `workspace.db` 和现象一起报给我们。

**测试数据源提示“无法运行程序”。**
直连需要本机有 `psql`（`brew install libpq`），经 ssh 需要本机有 `ssh`。见[第 4 章](04-datasource.md)。

**经 ssh 的数据源连不上。**
OneDesk 的 ssh 不会问密码。先在终端里 `ssh <主机>` 确认免密码登录，再检查服务器上有 `docker`、容器名对、容器里有 `psql`、用户和库名对。

**为什么我只能跑 SELECT？**
这是故意的：所有查询在只读事务里运行并回滚，一次一条，只允许以 `SELECT`、`WITH`、`VALUES`、`TABLE`、`EXPLAIN`、`SHOW` 开头。

**运行时提示“没有数据源”。**
给这条 SQL 选一个数据源，或在环境里设 `datasource`，或在工作区配置里设 `datasource.default`。见第 4 章。

**“AI 访问”页开了，Claude Desktop 还是看不到东西。**
依次检查：总开关是否打开；资源是否标了“对 AI 可见”；动作是否是插件声明为“AI 可用”的；改完配置后是否重启了 Claude Desktop。见[第 7 章](07-mcp.md)。

**点“分析”提示“这个环境不允许使用 AI”。**
当前环境的 `ai.policy` 是 `off`。让管理环境的人改，或换一个环境。见[第 6 章](06-ai.md)。

**提示“还没有设置 AI 连接”。**
先建一个 Anthropic 或 Ollama 连接，再设成默认（第 6 章）。

**Ollama 测试连接说没有下载任何模型。**
在终端运行 `ollama pull <模型名>`，再回来。

**怎么换界面语言？**
设置里选语言：简体中文、English、日本語。

**我能删掉一个内置插件吗？**
能停用（每个工作区各自设置，不删数据）。

**我删错了东西。**
先看“已删除”（可恢复）和资源自己的修改历史，再考虑从备份恢复。见第 2 章。

**哪里能看到谁/什么做了什么？**
审计页：记录每次修改、运行、导出，也包括 AI 客户端的调用。

界面语言在窗口底部状态栏右侧的“语言”（地球图标）菜单里切换。
