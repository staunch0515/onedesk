# 2. 数据目录、备份与恢复

## 数据在哪

```
~/Library/Application Support/onedesk/
```

（`~` 是你的用户文件夹。在 Finder 里：“前往 → 前往文件夹…”，粘贴上面这一行。注意是你用户文件夹下的 `Library`，不是磁盘根目录的 `/Library`。）

开发版本用 `onedesk-dev` 这个名字，和正式版互不干扰；你用的是正式版，只会看到 `onedesk`。

## 里面有什么

下表是源码里确认过的部分；目录里还可能有别的运行时文件，**别手动改里面的东西**。

| 位置 | 是什么 |
|---|---|
| `workspaces/<文件夹>/` | 每个工作区一个文件夹。首次是 `workspaces/default/` |
| `workspaces/<文件夹>/workspace.db` | 这个工作区的全部内容（SQLite 数据库）：资源、修改历史、审计、运行记录 |
| `workspaces/<文件夹>/workspace.json` | 工作区的名字、编号、窗口位置 |
| `workspaces/<文件夹>/backups/` | 自动留的数据库副本（见下） |
| `plugins/<插件 id>/<版本>/` | 已安装的插件。内置插件每次启动时从应用里复制过来 |
| `plugin-data/<插件 id>/` | 插件自己的文件夹。例如数据源插件的“备份到本机”转储文件在 `plugin-data/org.onedesk.datasource/backups/` |
| `trash/workspaces/` | 你“删除”的工作区会被移到这里，不是真删 |
| `mcp.sock` | 应用开着时给 `onedesk-mcp` 用的本机连接（路径太长时放在系统临时目录）。不是数据 |

**密码和 API 密钥不在这里**：它们只存在 macOS 钥匙串里。数据库、导出文件、备份里都没有明文。

## 自动备份

每个工作区每次打开时，如果当天还没有副本，就把 `workspace.db` 复制到 `workspaces/<文件夹>/backups/<年-月-日-时分秒>.db`（UTC 时间），**保留最近 7 份**，更早的自动删除。如果这次打开要升级数据库，不管当天有没有，都会先留一份升级前的副本。

你自己放进 `backups/` 的文件（名字不是这种时间格式）不会被动。

## 备份：两种做法

**做法 A：整个复制（最简单、最完整）**

1. 退出 OneDesk（工作区在用时不要直接复制数据库文件）。
2. 把整个 `~/Library/Application Support/onedesk/` 复制到别处（外接硬盘、网盘、Time Machine 都行）。

这样备份的是全部工作区和插件，**不含钥匙串里的密码和 API 密钥**——换电脑后要重新填。

**做法 B：导出工作区（可读的 JSON，适合分享给同事）**

右上角“设置”菜单（齿轮）→ **导出工作区…** → 输入一个还不存在或为空的文件夹的完整路径 → 导出。导出的是可直接阅读的 JSON，**不含密钥的值**，也不含工作区配置。

> 如果工作区开了“禁止导出”保护（`protection.no_export`），这里会被拒绝，需要先到设置它的工作区配置或环境里关掉。

## 恢复

**从做法 A 的备份恢复**

1. 退出 OneDesk。
2. 把备份的 `onedesk` 文件夹放回 `~/Library/Application Support/`（先把现有的改个名保留，别直接覆盖）。
3. 重新打开 OneDesk。密码和 API 密钥要在钥匙串里重新有——同一台电脑一般还在；换电脑要重新填。

**只恢复某个工作区的某个旧状态**（例如昨天的数据库）

1. 退出 OneDesk。
2. 把 `workspaces/<文件夹>/workspace.db` 改名留着，把 `backups/` 里想要的那份复制出来，命名为 `workspace.db`。
3. 重新打开。

> 待确认：只替换 `workspace.db` 时，旁边可能还有 `workspace.db-wal`、`workspace.db-shm` 两个临时文件；替换前请一并移走。我们没有专门测过这条恢复路径的所有边角，重要数据请先做好做法 A 的整体备份。

**从导出的 JSON 恢复**

设置菜单 → **导入…** → 输入导出所在文件夹的完整路径 → 先看预览（会新建几条、更新几条、哪些不导入及原因）→ 确认。导入的内容放进一个以来源工作区命名的新分组里；工作区配置不导入。导入需要的插件版本本机没有时，那些条目会列在“不导入的”里。引用的密钥会标出“本机已有 / 本机没有”，没有的要自己补。

**误删了条目**

先别急着恢复备份：删除的资源在“已删除”里可以恢复；每条资源的修改历史里也可以把某个字段恢复成旧值。
