# 9. 演示工作区：把新功能都摸一遍

书、课本和练习、文书、库存账本、凡例、修订提案、身份和签名、收件箱、程序书——每样都放了一个现成的例子，再加一本《OneDesk 导览》告诉你每个例子去哪里看、动手试什么。

## 打开

在仓库目录里运行：

```bash
pnpm demo
```

- 第一次会编译并建演示数据（一两分钟），以后直接打开。
- 终端里会打印一个网址，在浏览器里打开它（界面是中文）。
- 用完在终端按 Ctrl+C。

想从头再来（把动过的例子都还原）：

```bash
pnpm demo --fresh
```

## 放在哪里

全部在 `~/OneDesk-演示/`，和正式的应用数据（`~/Library/Application Support/onedesk/`）分开：

| 文件夹 | 是什么 |
|---|---|
| `数据/` | 演示工作区本身 |
| `信件/` | 来件、回件和身份卡（收件箱的例子用） |
| `输出/` | 发布的书、构建的插件包写到这里 |
| `李老师的数据/` | 寄来件的“李老师”的工作区（只用来写那封信） |

身份的私钥存在钥匙串里开发用的条目（服务名 `onedesk-dev`），不是正式应用的。

## 从哪里开始

打开左边的《OneDesk 导览》，点“开始阅读”。每一章一个功能，正文里的蓝色名字点了就打开那个例子。
