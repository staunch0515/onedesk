# 外部服务器需求（发现与连接）

状态：需求草案，待你确认。与 docs/requirements.md I.10d（家庭服务器）分开。
依据：D164（网页访问）、D165（家庭服务器）、D166（范围）。

## 1. 目的

让不在家里的设备找到家里的服务器并连上。这台服务器只负责"发现"和"连接"，不做其他事。

插件发布与下载、其他服务，不在本文档范围内，另行设计。

## 2. 发现与连接

- 家里的服务器启动后，主动向这台服务器登记自己在线、可以连接。家里不需要开放端口。
- 外部设备通过这台服务器找到家里的服务器，建立连接。
- 连接可以是直连，也可以经由这台服务器转发。直连失败时，才转发。
- 转发时只传输数据，不保存内容；传输加密，这台服务器无法读取明文。
- 家里的服务器离线时，外部设备显示"家里的服务器不可用"，不影响服务器本地数据。

## 3. 设备和权限

- 每台外部设备都要经过授权才能连接。授权在家庭服务器上完成，可以随时撤销。
- 授权方式待定（见第 5 节）。

## 4. 数据与隐私

- 这台服务器不保存用户数据内容。
- 只保存：在线登记信息（服务器地址、在线状态）、设备授权的摘要（不含内容）。

## 5. 待决定

1. 设备授权方式：配对码、扫码，还是账户登录。
2. 直连失败时是否默认转发，还是让用户选择。
3. 登记信息的保留时间。
4. 服务器部署在哪里、由谁运维。
