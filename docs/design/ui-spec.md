# 界面规格总表

依据：docs/requirements.md（I.0a–I.0h、I.1–I.11）；docs/decisions.md。
状态标记：已定 = 已在需求或决定中写明；默认 = 我按现有原则补的默认值，待确认；待定 = 需要你决定。

## 1. 窗口与布局

| 位置 | 内容 | 状态 |
|---|---|---|
| 顶部栏 | 工作区名、全局搜索、新建、命令面板、设置 | 已定（I.0h） |
| 左侧：树区 | 树的集合，每棵树一个标签页之外的入口 | 默认：树区按工作区分段，段标题为树名 |
| 中间：标签栏 | 标签列表，关闭、固定、关闭全部、显示全部 | 已定（I.0h） |
| 标签页内容 | 标题区、操作区、内容区、结果区 | 已定（I.0d、I.0h，SQL 见 sql-plugin §2b） |
| 结果区 | 下方可拖动、可收起；页签由插件决定 | 已定（I.0d） |
| 状态栏 | 左：工作区、环境、数据源；中：进度；右：同步、版本化、语言 | 已定（I.0h） |
| 最小窗口 | 1280 × 720 | 已定（架构文档） |

### 1a. 标签栏（窗口中的标签页列表）

| 项目 | 规则 | 状态 |
|---|---|---|
| 显示 | 所有打开的标签页排成一行，每个标签有类型图标、名称、关闭按钮；当前标签高亮 | 已定（I.0h）|
| 固定 | 固定的标签排在最前，只显示图标，不被“全部关闭”关闭 | 默认 |
| 溢出 | 标签太多放不下时，标签栏可以横向滚动；右侧出现“全部标签”按钮，点开列出所有标签页，可搜索、可切换 | 默认 |
| 全部关闭 | 标签栏右端一个按钮“关闭全部”；固定的标签不被关闭；未保存的内容先询问 | 已定（I.0h），未保存询问 默认 |
| 关闭其他 | 右键标签：关闭、关闭其他、关闭右侧、固定 | 默认 |
| 顺序 | 可以拖动标签改变顺序 | 默认 |
| 重启恢复 | 重启后恢复打开的标签页和顺序（界面状态，不版本化，D159） | 已定 |
| 键盘 | ⌘W 关闭当前；⌘⇧W 关闭全部；⌃Tab 切换下一个 | 默认 |

## 2. 树

| 树 | 节点 | 工具栏 | 右键 | 状态 |
|---|---|---|---|---|
| 资源树 | 分组、资源、综合节点、SQL 的历史子节点 | 全部展开、全部折叠、新建分组、过滤 | 由节点所属的插件提供（D197）；框架提供通用的右键机制 | 已定 |
| 环境树 | 环境 | 同上 | 由框架提供的环境相关项，插件可扩展（D197） | 已定 |
| 工作区配置树 | 配置项（如界面语言、外观） | 同上 | 由配置项所属的插件或框架提供（D197） | 已定 |
| 插件树 | 插件 | 同上 | 由框架提供：启用、停用、打开插件页（D197） | 已定 |
| 数据源树 | 数据源连接 | 同上 | 由数据源所属的插件提供（D197） | 已定 |
| 文件树 | 文件夹（授权文件夹为根） | 同上 | 由硬盘文件插件提供（D197） | 已定 |

树的通用规则：悬停只改背景；拖拽行为由插件决定（I.0g）；节点点击在标签页中打开。

## 3. 对话框与提示

| 项目 | 规则 | 状态 |
|---|---|---|
| 对话框 | 只在必要时使用，如系统的文件选择、永久删除的二次确认、删除工作区的确认 | 已定（I.0c、I.10） |
| 提示条 | 页面内的错误和警告，留在结果区或页面顶部，不自动消失 | 默认 |
| 吐司 | 短暂的成功反馈，约 3 秒后消失，可手动关闭 | 默认 |
| 通知 | 长任务完成、冲突出现等需要用户注意的事件，进入状态栏右侧的通知入口 | 默认 |

## 5. 首次启动与工作区

- 首次启动：没有工作区时，进入欢迎页。欢迎页是一个插件提供的标签页（D196），提供“从模板新建”“复制现有工作区”两个入口。
- 新建工作区：在标签页中完成，不用对话框：选择模板或现有工作区，填写名称。 默认
- 切换工作区：在当前窗口打开（替换）或新窗口打开。 已定（I.10）
- 删除工作区：在工作区配置页中，需要二次确认，说明不可撤销。 已定（I.10）

## 6. 键盘

- ⌘K：搜索并聚焦；⌘⇧P：命令面板；⌘N：新建资源；⌘W：关闭当前标签页；⌘⇧W：关闭全部标签页；⌘S：保存当前编辑；⌘1…⌘9：切换树区；⌘,：设置。 默认
- 所有可点击的操作都能用键盘完成；焦点有清楚的可见样式。 已定（I.0 的“键盘”要求）

## 7. 每个页面的状态

- 加载中、空、错误三种状态，每个页面都有（已定）。
- 空状态：一句话说明下一步可以做什么，不放插图（已定）。
- 错误：给出原因和处理方式（已定）。
- 停用的插件和失效的资源：灰色显示，不隐藏（已定）。

## 7a. 标签页内的列表

用于综合节点的资源、SQL 的历史、文件夹的文件、搜索结果等。与结果区的表格使用同一组件，只是可选的列不同。

| 项目 | 规则 | 状态 |
|---|---|---|
| 样式 | 一行一条；左侧是类型图标；名称在前，其余信息（类型、分组、时间、大小）按列显示 | 默认 |
| 列 | 每种列表由所属插件给出列定义；列可以隐藏，列宽可拖动并记住（I.7） | 已定（I.7），列定义默认 |
| 排序 | 点列头三态切换：升序、降序、取消；列头显示方向 | 已定（I.7） |
| 选择 | 单击选中；⌘ 点选多条；⇧ 点选连续范围；⌘A 全选 | 默认 |
| 键盘 | ↑ ↓ 移动；回车打开；⌫ 删除（进废纸篓或移除引用，由插件决定）；空格预览 | 默认 |
| 打开 | 双击或回车在标签页中打开；单击不打开 | 默认 |
| 右键 | 由所属插件提供（D197） | 已定 |
| 拖拽 | 由所属插件决定（I.0g） | 已定 |
| 过滤 | 列表顶部有过滤框，输入即过滤；与全局搜索分开 | 默认 |
| 空状态 | 一句话说明下一步（I.0 的状态要求） | 已定 |
| 大列表 | 一万条以上仍然顺畅滚动（只渲染可见行）；超出时显示总数 | 默认 |
| 分组 | 可以按列分组显示，分组标题可折叠 | 默认 |
