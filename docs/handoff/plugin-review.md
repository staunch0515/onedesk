## 外壳 / 内核（已做，D467）

- 内核：页面默认使用环境（`usesEnv` 默认 `true`）。外置插件里没写 `usesEnv` 的页面现在也都有环境选择；显式写 `false` 的（如数据源编辑页）没变——这部分归 ext-plugins 会话按同样五条处理。
- 外壳：“添加参数”可输入任意名称和值；内核认识的参数变成快捷选项。
- 外壳：页面视图状态 `view.<名字>`（操作栏切换按钮用，不再需要页面里的控件）。
- 外壳：从页面里打开的内容沿用这个标签页的环境。
- 信息面板：内核本来就给所有资源页（`hasInfo`）；没有插件自己再画名称/描述字段。
