## 没做到 / 没验证

- 桌面窗口里的画面和操作、打包出的 `.app`（外部程序在打包后的应用里能否找到、能否运行没验）、真钥匙串、https。
- 没有系统级沙箱：外部程序能访问用户能访问的一切（设计如此，靠安装时的确认和 `process.allow`）。
- “升级多了程序要重新确认”：经安装对话框安装时安装本身就是确认；“未确认”状态只由内核测试覆盖，没有界面检查。
- D339 已知限制：运行的宿主接口可被插件存起来在运行期间从别的上下文使用（记 `todo.md`）。
- 示例插件页面上“最近一次运行”显示的是原始的状态词和 ISO 时间（夹具的写法，不是外壳问题）。
