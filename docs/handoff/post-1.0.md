## 第二十轮逐页检查新增（外壳/内核，均不影响使用）

- 配置页的“外观”（`ui.theme`）是自由文本框，应是 light/dark/system 下拉：内核的参数类型需要带选项（内核）。界面外观平时用状态栏切换。
- 修改历史表“改了什么”列显示内部字段名（如 `name`），应显示字段标签（外壳+内核）。
- 插件树里长名字（如 “Chinese (Simplified) language”）被截断，无悬停全名（外壳）。
- 信息面板顶部面包屑与标题重复显示同一名字（外壳设计取舍）。

## 第二十轮独立审查留下的（可记入 1.0 之后）
