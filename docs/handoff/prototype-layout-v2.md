## 用户的要求与做法

在现在的界面上改：顶栏、状态栏、标签页、侧栏树都保留。

| 编号 | 要求（2026-11-24） | 原型的做法 |
|---|---|---|
| 1 | 标签页保留；标签的字体和高度都小一点；标签栏、面包屑、按钮三行规格一致 | 三行共用一组 token：行高 32px、文字 12px、图标 14px，行内控件（按钮、“…”、环境选择器、信息面板开关）高 26px（`--chrome-*`，只在新布局下生效）。侧栏标题行跟着标签栏，两边齐平 |
| 2 | 信息面板：宽屏放左边，普通屏放右边 | 窗口 ≥ 1600px 时在内容左侧（靠近树），< 1600px 时在右侧，跨过分界自动换边；折叠、拖宽、记住宽度照旧。分界线以后交给插件或设置 |
| 3 | 去掉标题行，面包屑的当前标题加粗 | 面包屑一行：路径可点，最后一项是当前页面名称，加粗（仍是页面的 `h1`），类型/状态/未保存等徽标紧跟其后 |
| 4 | 按钮放在面包屑的下一行，靠左；环境选择和按钮在同一行，放在最左（最重要） | 第二行：环境选择器在最左，一条细线后是执行、保存等按钮（多于 4 个进“…”）；信息面板开关在这一行最右 |
| 5 | 去掉图标栏和树上方的工具栏 | 已去掉 |
| 6 | 图标栏最上面加一个切换宽度的图标 | 窄模式：和现在一样（最上面多一个切换按钮）。宽模式：图标栏变宽（280px），结构与旁边的树面板一致——标题行“视图”在左、切换图标在右（与“资源”标题行同高、齐平），下一行“查找视图”搜索框（与“按名称过滤”对齐），下面所有视图以大图标 + 名称排成网格（像 Mac 的“应用程序”）；当前视图高亮、运行中的数量照常显示；设置在底部。侧栏树照常在右边。宽/窄状态会记住。以后视图多了可在搜索框下加分类标签 |

## 改动

- 设计系统：`PageTitleBar` 增加 `crumbs`（面包屑行 + 按钮行）和 `lead`（按钮行最前：环境选择器），`InfoPanel` 增加 `side`，`ActivityBar` 增加 `wide` / `onToggleWide`（宽模式：搜索 + 图标网格）；样式在 `page-frame.css`、`workbench.css`、`tab-strip.css`；新 token：`--activity-wide-width`、`--activity-tile-width`、`--activity-tile-icon`、`--chrome-row-height` / `--chrome-text` / `--chrome-leading` / `--chrome-icon` / `--chrome-control-height`（新布局下标签栏 = 面包屑行 = 按钮行）。
- 外壳：`frame.tsx`（两行页头、信息面板换边）、`workbench.tsx`（图标栏切换）、`state/layout-mode.ts`（新/现状开关、1600px 分界）、`state/store.ts`（`activityWide`，随界面状态保存）、`hooks.ts`（窗口宽度）、`info-panel.tsx`、`main.tsx`。
- 文字：新增 4 个键（`activity.wide/narrow/filter/noMatch`，英、中、日）。
- 不涉及内核、协议、插件代码。
