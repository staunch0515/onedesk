# 桌面实机检查清单（给用户，2026-11-18）

这些我们（各会话）都做不了：没有截屏权限，不能碰真钥匙串，打包的应用从命令行启动时停在系统的图形启动阶段。每项大约 1–3 分钟。看到“应该看到”以外的东西，把**项号 + 看到了什么（截图最好）**发给协调会话就行。

开始前：
- 在 `/Users/zhongpingxue/onedesk/repo`（main）里执行 `pnpm install`、`pnpm start`。第一次会编译几分钟。
- 你的数据目录是 `~/Library/Application Support/onedesk/`。第一版的 `onedesk.db` 按你的决定不升级、也不会被动；新版本会在同一目录下建 `workspaces/`。如果想完全隔离，可以先把整个目录改名备份。

| # | 怎么做 | 应该看到 |
|---|---|---|
| 1 | `pnpm start` | 一个窗口：左边活动栏和资源树，右边欢迎页；没有报错提示条 |
| 2 | 欢迎页点“新建笔记”，写几个字，⌘S | 树里出现笔记；关掉窗口再 `pnpm start`，笔记还在、内容还在 |
| 3 | 新建网址 `https://example.com`，点“打开” | 系统默认浏览器打开这个网址 |
| 4 | 新建 HTTP 请求，地址 `https://httpbin.org/get`，发送 | 第一次会问是否允许访问该地址；允许后看到 200、耗时、JSON 排版的正文（这是第一次真正走 https） |
| 5 | 设置一个密钥：在 HTTP 请求的“令牌（密钥）”里新建一个名字叫 `od-test`、值随便写的密钥，请求头里加一行 `X-Test: {{token}}`，再发一次到 `https://httpbin.org/headers` | 系统可能弹钥匙串授权，点“允许”；响应正文里 `X-Test` 是你写的值。之后在“钥匙串访问”里搜 `onedesk` 能看到这一条（检查完可删） |
| 6 | 状态栏右下角切换语言到日语、再切回中文 | 界面文字立即变化；欢迎页的介绍跟着变 |
| 7 | 设置里切换深色、浅色 | 全部区域跟着变，没有看不清的字 |
| 8 | 左上角工作区菜单 → 新建工作区“测试” | 列表里多了“测试”；当前窗口还在原来的工作区 |
| 9 | 工作区菜单 → 在新窗口打开“测试” | **新开一个窗口**，标题栏显示“测试”，树是空的；原窗口不变 |
| 10 | 把新窗口拖到别处、改大小，关掉，再从菜单用新窗口打开“测试” | 窗口回到你上次放的位置和大小 |
| 11 | 两个窗口都开着时，在第一个窗口的“管理工作区”里删除“测试” | 被拒绝，提示正在使用；关掉第二个窗口后再删 → 成功；`~/Library/Application Support/onedesk/trash/workspaces/` 下有它 |
| 12 | 退出应用（⌘Q） | 进程全部退出：“活动监视器”里搜 `onedesk` 没有残留 |
| 13 | 打包：`pnpm tauri build`，打开 `src-tauri/target/release/bundle/macos/` 下的 `.app`（双击） | 和 1 一样能打开、能用；如果打不开或系统提示“已损坏/无法验证”，截图发来 |

做完 5、11 后，如果想清理：钥匙串里删掉 `od-test`；`trash/workspaces/` 里的文件夹可以直接删。
