# 阶段 0：工作台界面原型（交接）

分支 `redesign/stage-0`，未提交。全部是假数据；界面只经 `ProtocolClient` 接口工作，之后把假实现换成真内核即可保留为正式外壳。

## 1. 怎么运行

```bash
pnpm install
pnpm exec vite --port 1431 --strictPort      # 或 pnpm preview:web（端口 1421）
```

打开 `http://localhost:1431/workbench.html`（`pnpm preview:web` 时为 `http://localhost:1421/workbench.html`）。

地址参数（截图脚本也用）：`?reset` 重置演示数据和布局；`?quiet` 启动时不带那条进行中的“导入文件夹”；`?theme=light|dark`；`?density=compact`；`?lang=zh-CN`。命令面板里的“Reset demo data and layout”等同于 `?reset`。

界面检查与截图：

```bash
E2E_PORT=1432 pnpm exec playwright test e2e/workbench.spec.ts
```

它会重新生成 `docs/screenshots/workbench-{light,dark}-{sql,env,plugin,tree-menu,tasks}.png`（1280×800）。设 `WB_SHOT_DIR=<目录>` 时另存 1600×1000 的对照图。

## 3. 已实现（都可点击）

- **活动栏**：资源、环境、工作区配置、插件、数据源、文件、运行记录、收藏、已删除；底部设置。再点一次当前项收起侧栏。
- **侧栏的树**：工具栏（新建分组、全部展开、全部折叠、过滤框）；无限嵌套；折叠状态记住；悬停只改背景；五种节点状态（正常 / 停用灰色 / 缺少插件 / 失效 / 冲突）；右键菜单（命令来自协议）；行内重命名；拖到分组里移动、拖到行的上下边缘排序；无效位置显示统一的“不可放置”（行变红 + 跟随指针的提示 + 禁止光标）；拖动时悬停折叠的分组约 0.7 秒自动展开；树跟随当前标签页（自动展开并高亮）。文件树是“提供树”，子节点按需加载。
- **顶部栏**：工作区名（下拉）、搜索框（⌘K 聚焦，下拉结果，↑↓ 回车）、新建（下拉）、命令面板（⌘⇧P）、设置。
- **标签栏**：类型图标、关闭按钮、未保存圆点、固定（只显示图标、排最前）、横向滚动、全部标签列表（可查找、可关闭）、关闭全部（固定的保留）、拖动排序、右键（关闭、关闭其他、关闭右侧、关闭全部、固定）、折叠标签栏；刷新后恢复标签和顺序。关闭有未保存修改的标签先询问。
- **页面框架**：面包屑（树中的路径，可点）、标题、操作区（最多 4 个 + 更多）、每个标签页自己的环境选择、内容区、右侧信息面板（名称、位置、类型、说明、标签、来源、创建/修改记录；可收起；宽度固定、可拖）、下方结果区（高度可拖、可收起、子页签）。
- **状态栏**：左 工作区 / 标签页环境 / 数据源；中 进度或上次结果摘要；右 演示数据标记、任务数、密度、明暗、语言（立即生效）。
- **任务面板**：进行中和刚结束的运行，进度、取消、清除已结束；点标题打开那次运行。
- **页面**
  - SQL：参数条（文本、数字、日期、带预设的日期时间、枚举）；编辑区占满剩余高度（行号、着色）；执行 / 保存 / 保存并执行 / 格式化，更多里有执行计划等；输入 `:name` 停止约 300 毫秒后参数条多一项；结果区页签：结果（三态排序、列宽可拖并记住、表头固定、行号列固定）、最终 SQL、历史（点一行在新标签页打开那次运行）、AI 分析占位。执行有进度再出行；“退款对账 Refund reconciliation”会失败，错误留在结果区；“清理过期会话”在只读环境被策略拒绝；“Long-running export”约 15 秒，可取消。
  - 环境：父链面包屑、说明、参数表（每个值的来源层、可覆盖、改用继承值、“已变化”标记与“保留本环境的值”、“不生效”标记）、历史列表与恢复（恢复本身也记入历史）。
  - 插件：说明、加载状态、启用开关、版本列表（使用中 / 固定 / 启用此版本）、设置项、权限、提供的类型和动作。停用 SQL 插件后资源树里它的资源立即变灰；Slack 插件演示加载失败，切到 0.1.4 后恢复。
  - 笔记（第二种类型）：绑定字段的表单 + 占满高度的正文。
  - 数据源（第三种类型）：表单 + “测试连接”。
  - 运行记录页：某次运行作为标签页打开（当时的 SQL 和参数只读、结果、最终 SQL、“复用参数”、“保留结果”）。
  - 审计：带过滤条件的表格。已删除：恢复、永久删除（二次确认）。
- **主题与密度**：浅色 / 深色 / 跟随系统，宽松 / 紧凑；写在工作区配置里（设置 → 外观 页也能改，立即生效）。
- **分割线**：侧栏、信息面板、结果区、表格列，都可拖，尺寸记住，拖动时光标统一、不选中文字；双击恢复默认。
- **键盘**：⌘K、⌘⇧P、⌘S、⌘↵（执行）、⌘W、⌘⇧W、⌘N、⌘B（侧栏）、⌘J（结果区）、⌘,、⌘1…9、⌃Tab。

## 4. 哪些是假的

- 全部数据：约 30 条资源、4 个环境（默认 → 测试；默认 → 正式 → 只读副本）、9 个插件、40 多条运行、160 条审计、文件树。保存在浏览器 localStorage（键 `onedesk.workbench.mock.v3`）。
- 执行：定时器模拟进度，结果由固定种子生成；“最终 SQL”只是把 `:name` 换成值。
- SQL 参数识别、类型推断（按名字后缀）、格式化（只把关键字改大写）是假内核里的几行代码。
- 导出 CSV / .sh / Markdown、复制、复制链接、检查更新、安装/卸载插件、切换/新建工作区、导入文件：只弹提示。
- AI 分析：占位。
- 事件：同一页面内的回调，不是套接字。

## 5. 没做或没验证

- 验证方式：`e2e/workbench.spec.ts` 24 项（真实鼠标键盘事件：执行、失败、历史开新标签、`:name` 加参数、树拖放与不可放置、重命名、过滤、折叠记忆、标签固定/拖动/关闭全部/刷新恢复、未保存询问、三条分割线与列宽、三态排序、语言/密度/主题、环境覆盖与恢复、插件停用与版本切换、搜索、命令面板、审计、新建后首次保存才创建、笔记、数据源、取消运行、删除与恢复），加上逐张看截图。没有人手点过。
- **只在 Chromium 里验证过**（Playwright 无头 + 应用内浏览器面板），没有在 Tauri 的 WKWebView 里跑。编辑器用“透明 textarea 叠在着色文本上”，日期用原生控件，这两处在 WebKit 里的表现需要实测。
- 应用内浏览器面板缩放后只有 800×500，细节靠 Playwright 的 1280×800 和 1600×1000 截图逐张看；1600×1000 只看了 SQL、环境、插件三页。紧凑密度只验证了能切换，没有逐页看。
- 浏览器里 ⌘W、⌘N、⌘1…9 会被浏览器自己拿走，这几个快捷键只有代码，没有验证；Tauri 里应当有效。
- 未保存内容不跨刷新保留；“未保存时底层资源被别处改了”的合并提示（内核设计 9.3）没做。
- 已知的外观问题：吐司出现在右下角，会短暂盖住任务面板的底部和状态栏右端；标题栏很窄时（1280 宽 + 侧栏 + 4 个按钮 + 环境选择）长标题会被截断。
- 打字延迟没有量（规划里阶段 0 要量的那一项）。
- 表格没有做虚拟滚动（结果最多显示前 1000 行）；树也没有。
- 自定义节点 / iframe 页面（9.4）不在本原型内。
- 资源树里 “SQL 的历史子节点”“综合节点”没做；通知入口没做；欢迎页只是“首次打开的一组标签页”。
- 新增的设计组件没有单元测试，也没有加进设计系统的 gallery。

## 6. 规格里不明确的地方和我选的默认值

1. **入口**：做成单独的 `workbench.html`（不改 `src/main.tsx`、不改 `vite.config.ts`）。`pnpm build` 目前不会把它打包进去，正式采用时再把入口换掉。
2. **活动栏与“树区分段”**：ui-spec §1 说“树区按工作区分段，段标题为树名”，§9 又说活动栏切换侧栏内容。选了 VS Code 的做法：活动栏每个图标对应一棵树，侧栏一次只显示一棵。
3. **收藏、已删除、运行记录**：做成活动栏上的三棵树（ui-spec 把收藏写成“树区中的一段”）。
4. **结果区与信息面板的位置关系**：结果区横跨整个页面宽度，信息面板只占内容区那一段高度（sqlpool 的信息栏在左侧，这里按内核设计 9.3 放右侧）。
5. **信息面板开合、结果区开合与尺寸**：全窗口共用一份，不按标签页分别记。
6. **单击树节点**：直接打开为普通标签页，没有 VS Code 的“预览标签页（斜体）”。分组没有自己的页面，单击只是展开/折叠。
7. **同一目标只开一个标签页**；历史里点一次运行是另一个目标（`run:<id>`），所以总是新标签页。
8. **新标签页的位置**：加在最后（不是当前标签的右边）。
9. **固定标签**：固定时移到固定段的末尾；固定的标签没有关闭按钮，⌘W 也不关它；拖动不能越过固定/非固定的分界。
10. **标签栏折叠**：折叠后只剩右端三个按钮那一条，不是完全消失。
11. **“当前环境”标记**：环境是每个标签页的，没有全局当前环境。做法：环境树里给“当前标签页所用的环境”加绿点；环境页标题旁显示“N 个打开的标签页在用”；新标签页默认用上一次选过的环境。
12. **参数条里来自环境的值**：显示为占位文字 + 一个小图标（悬停说明来自哪个环境），用户输入即在本标签页覆盖；没有把“环境里已有的参数”隐藏掉。
13. **参数说明**：按 I.7 用图标加悬停；环境页的参数名后不放说明图标，只放“被几条资源用到”的数字。
14. **环境页的历史**：放在页面框架的下方区域（与结果区同一位置、同一高度记忆），只有“历史”一个页签；ui-spec 提到的“保护设置”没有单独做，保护类参数就在参数表里。
15. **环境参数的编辑**：改完失焦或回车立即写入并记历史，没有“保存”按钮；密钥只显示钥匙串条目名、只读；引用（数据源）只读加“打开”。
16. **未在任何层设置、但被资源用到的参数**：也列在环境页（来源显示“各层都没有设置”），可以直接填。
17. **配置页**：用同一个表单页，改了立即保存（没有保存按钮）；语言、主题、密度按 D192 当作工作区配置参数。
18. **操作区“最多三到四个”**：取 4 个，其余进“更多”；主动作排第一。标题栏太窄时标题先保留、徽标先被挤掉。
19. **未保存标记**：标签上的圆点 + 标题旁的“未保存”徽标。
20. **关闭未保存的标签**：一个对话框三个按钮（保存 / 不保存 / 取消）；一次关多个时只问一次。
21. **错误**：运行错误留在结果区直到下一次运行或“清空结果”；协议调用失败（保存失败等）用吐司，3.5 秒。
22. **任务面板的位置**：状态栏右端上方的浮动面板，非模态，点状态栏的任务数开合。
23. **通知入口**：没做（ui-spec §8 待决定）。状态栏右侧放的是任务、密度、明暗、语言；I.0h 写的“同步、版本化”状态没有放。
24. **搜索**：顶部是真的输入框加下拉结果，不是点开命令面板；命令面板只放命令。
25. **列表的单击/双击**（ui-spec §7a）：文件夹列表按规格“单击选中、双击或回车打开”；历史列表单击就打开（按 I.5“点击历史记录”）。
26. **拖拽**：用指针事件自己实现，没有用 HTML5 拖放（Tauri 的窗口会拦截它，光标也控制不了）。目标行中间 = 放进去，上下边缘 = 排到前后。
27. **界面文字的来源**：外壳文字在 `i18n/`；内核和插件给的文字（类型名、动作名、树名、命令名）经协议以“每种语言一份”的 `Label` 传来，切换语言不用重新请求。资源名等用户内容不翻译。
28. **日期和数字**：按当前语言用 `Intl` 格式化；结果表格里的值原样显示。
29. **节点状态的画法**：停用 = 灰；缺少插件 = 斜体 + 拼图标记；失效 = 删除线 + 断链标记；冲突 = 橙色 + 合并标记。页面顶部另有一条说明。
30. **表格列宽**：默认值写在页面代码里（数字），用户拖过的宽度按表格种类记住（结果按资源记）。
