# 任务说明：SQL 插件（验收样本）

状态：待开始，等待 docs/design/sql-plugin.md 确认。
依赖：m2-tree-and-tabs.md（树与标签页）必须先完成；D157（files，若需要）与本任务无关。

## 1. 目标

按 docs/design/sql-plugin.md 实现 `sql` 插件，覆盖其中对照表的全部功能，用它验收框架。

## 2. 允许修改的文件

- `src/plugins/sql/`（新建）：清单、插件入口、视图、测试。
- `src-tauri/`：仅限数据源连接所需的 PostgreSQL 驱动与只读执行命令，通过 `src/platform/contract.ts` 暴露。
- `src/plugin-api/`：不允许修改。如果插件需要的能力不在接口里，停下来写阻塞说明，不要自己加。

## 3. 完成标准

1. 设计文档 §2 对照表中的每一行都有对应测试，或在交接文件中说明为什么不做。
2. 界面测试覆盖：新建 SQL、运行、参数表单、切换环境、保存结果、复用历史参数、导出 CSV、AI 分析。
3. 写操作语句被拒绝；超时和行数上限生效。
4. 框架缺什么，写进 docs/handoff/ 的阻塞说明，并列出来，不绕过。
5. `pnpm check` 通过；截图保存到 docs/screenshots/。

## 4. 交付物

- 插件代码与测试。
- 交接文件：完成了什么，框架哪里不够，需要主会话决定什么。
