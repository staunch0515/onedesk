## 验收中发现并处理的

- HTTP 插件清单没按 D318 声明，请求头里的密钥引用被拒 → 请求头、请求体声明 `secrets: true`（地址是授权地址，不能同时声明，D320）。
- `0.2.0` 夹具的 `upgradesFrom` 用空格分隔被内核拒绝 → 改成逗号（D319）。
- 外壳 8 条（`round4-accept-findings.md`）：A1 密钥页误标“演示数据”、A3 设置菜单里没有密钥入口、A4 运行失败不说原因、A5 坏包不显示详情、A6 欢迎页按钮建的是分组、A7 地址输入框太窄——已修，我复看确认。A2 密钥表格超宽——外壳会话实测已修，我没再看到带数据的表。A8（升级后“上次运行”与结果区不一致）记入 `todo.md`，没修。
- 界面检查的重定向用例按 D317 已过时 → 改写；补“换端口被拒”“草稿密钥名被拒”。
