# OneDesk 1.1.0（2026-11-23）

## 安装包

| 文件 | 说明 |
|---|---|
| `OneDesk-1.1.0-macos-universal.dmg` | 应用安装包：打开后把 OneDesk 拖进“应用程序”。同一个包支持 Apple 芯片（如 iMac M1）和 Intel（如 Mac Pro Intel），macOS 11.3 或更新 |
| `OneDesk-1.1.0-macos-universal.zip` | 同一个应用的 zip，给不方便挂载 dmg 的机器 |
| `plugins/*.odplugin` | 可选插件，按需在“插件市场”或“安装插件…”里安装 |
| `SHA256SUMS` | 校验：`shasum -a 256 -c SHA256SUMS` |

应用只做了本机自签名，没有经过 Apple 公证：第一次打开请在 Finder 里**右键 → 打开 → 打开**，或执行 `xattr -dr com.apple.quarantine /Applications/OneDesk.app`。详见 `docs/manual/01-install.md`。

Windows 版暂不提供。

## 新内容

- **界面配色**：暖色中性底与陶土色强调色，选中态改为中性色，浅色/深色都按 WCAG AA 对比度检查。
- **AI 辅助**：配好 AI 连接（Anthropic 或 Ollama）后，文本字段旁有 ✨“用 AI 写”，多字段页面有“用 AI 填写”；默认先显示将发送的内容，结果是提议，接受后才进入页面（未保存）。
- **插件包**：插件以 `<id>-<版本>.odplugin` 文件发布和安装；插件市场能列出授权文件夹里的包文件；“安装插件…”可直接选包文件。以后增加功能只需发新插件包，不必重装应用。
- **应用只带基础插件**：欢迎、笔记、网址、提示词、文件、综合、插件市场、AI 工作台、Anthropic、Ollama、简体中文。

## 可选插件（本次随附）

数据源、保存的 SQL、查询目录、表、HTTP 请求、API 连接、服务器命令、本机脚本、集合、日语。

## 变更说明

- 欢迎页不再有“新建 HTTP 请求”（HTTP 请求成为可选插件；装上后可从“新建”菜单创建）。
- 原来选文件夹安装插件的命令改名为“从文件夹安装插件…”。
