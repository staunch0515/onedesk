## 2. 完成版是什么

一个可以交给自己和同事日常使用的 OneDesk 1.0：

1. **功能**：阶段 0–6 全部做完。sqlpool 的 90 项按 `sqlpool-parity.md` §5 逐行通过；AI 能接 Anthropic 与 Ollama（见 `ai-plugins.md`）。
2. **能装能用**：打出的 `.app` 能从 Finder 启动；首次启动有欢迎页；旧版本的数据目录能升级打开；崩溃后工作进程自动重启。
3. **质量**：完整 `pnpm check` 通过；`todo.md` 里影响日常使用的项清零，其余明确标为“1.0 之后”；浅色、深色和中英日三种语言都看过。
4. **文档**：用户手册（安装、数据目录、备份与恢复、数据源、查询目录、AI 设置）；插件开发说明（`plugins/README.md` 补全）。
5. **不包括**：阶段 7–9 的一切（git 同步、视频库、网页版、远程、市场的服务器端）。界面和协议里已为它们预留的位置保持不动，不删除。
