# 书：按角色设计（D487）

> **状态**：§0–§12 的思路由用户 2026-11-25 确认；§13 是第②步的详细设计，用户 2026-11-25 确认 §13.13 全部按设计稿，已实现（实际做法 §14）。§15 是第③步的详细设计，用户 2026-11-25 确认 §15.13 全部按设计稿，已实现（实际做法 §16）。§17 是第④步的详细设计，用户 2026-11-26 确认 §17.9 全部按设计稿，已实现（实际做法 §18）。§19 是第⑤步的详细设计，用户 2026-11-26 确认 §19.14 全部按设计稿，已实现（实际做法 §20）。§21 是第⑥步的详细设计，**待用户确认 §21.10**。
> **后面所有和书有关的开发都必须严格按本文的思路做**（§0）。每一步开发前，仍要先写那一步的详细设计给用户确认（§11）。
>
> **来源**：用户的思路（想了十几年），原话的要点：
> - 书本身很简单，只是组织子书和书里的页；
> - 页可以有各种各样的类型：已有的插件（如笔记），也可以是专属于书的页；
> - 高级的书插件，就是增加页的类型；
> - 书里有正文，也有附录等；深入参照实体书的设计和规范，就能解决很多问题；
> - 设计要有艺术：比如整本书浏览、分页的逻辑，应该放在“目录”这种页类型里。书的每一部分担当什么角色，就把相应的逻辑放进那个角色，功能的调整才灵活。
>
> **取代**：`documents.md` 的 §18（书的详细设计）、§22、§24–§29（活书五个阶段），以及 §20–§21 里“作答改成通用记录”的部分（见 §12）。`documents.md` 的 §19 课本需求仍然有效。

## 0. 必须遵守的原则

1. **书只负责装订。**
   - “书”这个类型只管两件事：书里有哪些页、按什么顺序；每一页担当什么角色。
   - 书的代码里**不写**任何角色的逻辑：怎么浏览、怎么编号、怎么发布、答案什么时候公开，都不写在书里。
2. **逻辑放在担当它的角色里。**
   - 实体书里哪一部分负责这件事，OneDesk 里就由那一类页负责：
     - 浏览和编号是**目录**的事；
     - 版本和发布是**版权页**的事；
     - 书给人看的样子是**封面**的事；
     - 引文是**参考文献**的事。
   - 同一个插件提供的几种角色，代码也分开写，互不伸手。
3. **加功能就是加角色，换功能就是换角色。**
   - 新的玩法一律做成新的页类型，比如“课本目录”“答案附录”“运行页”。
   - 不在书上加开关、加设置、加模式。
   - 想换一种浏览方式，就换一个目录页。
4. **先问实体书怎么做。**
   - 设计任何一个功能，先看实体书和出版规范里有没有现成的做法，有就照做，例如：
     - 结构：前面的部分、正文、后面的部分；
     - 编号：章节号、附录号、图表号；
     - 版次和印次；
     - 学生用书和教师用书；
     - 参考文献的著录规则（GB/T 7714）；
     - 书名页和版本记录（GB/T 12450）。
   - 实体书没有的东西（比如能运行的页），也按“它在书里担当什么角色”来想。
5. **内核不认识书。**
   - 书和各角色之间，通过书插件定义的**插件接口** `onedesk.book/1`（spec §3.5 的 `implements` / `uses`）配合。
   - 内核只提供通用能力：读子树、读内容、连续显示的视图节点、发布与只读副本等（§10）。
   - 内核里不出现“书”“目录”“章”这些词（硬性规则 1）。
6. **任何资源都能当页。**
   - 没有实现书接口的资源（笔记、图片、SQL 查询……）放进书里，都按**正文**处理，用嵌入（D481）显示。
   - 它本来能做的事，在书里照样能做（比如 SQL 查询能运行）。
7. **产品要求照旧**（spec §0）：
   - 一切都是资源，都有信息面板；
   - 每页可选环境；
   - 一个功能一个入口；
   - 不乱加东西；
   - 不显示内部名字；
   - 从“新建”开始真走一遍。

## 1. 参照：实体书的结构

| 部分 | 实体书里的组成 | 担当的角色（§3） |
|---|---|---|
| **前面的部分** | 封面、书名页、版权页（版本记录）、序、前言、目录、插图目录 | 封面、版权页、前言、目录、图表目录 |
| **正文** | 篇、章、节；正文；图、表、公式、例题；脚注 | 正文页；篇、章用分组 |
| **后面的部分** | 附录、参考文献、索引、后记、（课本的）习题答案 | 附录、参考文献、索引、后记、答案附录 |
| **套书** | 丛书、文集、多卷书（第几卷第几册）、配套练习册、教师用书 | 子书；版权页里的“版本”（学生版、教师版） |

几条照搬的规矩：
- **顺序固定**：前面的部分 → 正文 → 后面的部分。
- **编号**：
  - 正文编“第 X 章”；前言、序、后记不编号；附录编 A、B、C；
  - 图、表、公式按章编号（图 2-1、表 3-2、式（2-3））。
- **版次与印次**：内容改了是新的一版；内容不变、只是重新发一遍，是同一版的新一次印刷。
- **学生用书和教师用书**：教师用书多出答案和教学说明。

## 2. 书：只负责装订

| 项 | 内容 |
|---|---|
| 类型 | **书**（`org.onedesk.book` 的 `book`）：放在资源树，可以拖动；接受任何子节点；书里的书就是**子书** |
| 装订顺序 | 书按每一页的角色所在的部分（§3）维持“前面的部分 → 正文 → 后面的部分”。<br>• 往书里拖页时，落在它所属的部分之内；比如附录拖不到正文前面，会落到后面的部分的开头。<br>• 同一部分内的顺序就是树上的顺序，由用户拖动决定。<br>• 这是装订的规矩，所以由书管 |
| 打开书 | 看到的是它的**封面**页（§3.1）。没有封面时，显示书名和“开始阅读”。<br>“开始阅读”打开书的**目录**页的浏览（§4）。没有目录时，按装订顺序显示一个最简单的列表 |
| 被引用 | `![[书名]]` 显示封面给出的样子（§3.1）；`![[书名#第三章]]` 由目录解答（§4.5） |
| 新建 | “新建 → 书”：建好后自带一页**封面**、一页**目录**（实体书都有）。两页都能删、能换成别的类型 |
| 书自己存什么 | 只有名字。作者、版次等写在封面和版权页里，不写在书上 |
| 子书 | 子书有自己的封面、目录。外层的目录浏览到子书时，向子书的目录要它的内容（§4.4） |

## 3. 角色

每一页的角色由它的**类型**决定，类型在接口里声明（§5）。

| 角色 | 部分 | 一本书里 | 编号 | 由谁提供 | 带的逻辑 |
|---|---|---|---|---|---|
| **封面** | 前 | 最多 1 | 无 | 书插件 | 书给人看的样子 |
| **版权页** | 前 | 最多 1 | 无 | 书插件 | 版次、印次、发布、学生版和教师版 |
| **前言**（序、前言、致谢） | 前 | 不限 | 无 | 书插件 | 书外的话 |
| **目录** | 前 | 最多 1 | 无 | 书插件；别的插件可以提供别的目录 | 浏览、编号、阅读位置、交叉引用、导出 |
| **图表目录** | 前 | 最多 1 | 无 | 书插件 | 列出全书的图、表、公式 |
| **正文页** | 正文 | 不限 | 按章 | 书插件 | 内容、脚注、自己里面的图表 |
| **篇、章（分组）** | 正文 | 不限 | 按层级 | 内核的分组 | 只是容器 |
| （任何其他资源） | 正文 | 不限 | 按章 | 各插件 | 它本来的样子 |
| **附录** | 后 | 不限 | A、B、C | 书插件 | 自己的编号方式 |
| **参考文献** | 后 | 最多 1 | 无 | 书插件 | 文献条目、正文里的引注 |
| **索引** | 后 | 最多 1 | 无 | 书插件 | 收集标出的词 |
| **后记** | 后 | 不限 | 无 | 书插件（前言的一种） | 书外的话 |
| 练习页、测验页 | 正文 | 不限 | 按章 | 练习插件 | 作答、判分（§7） |
| 答案附录 | 后 | 不限 | A、B、C | 练习插件 | 只在教师版；公布（§7） |
| 课本目录 | 前 | 最多 1 | 无 | 练习插件 | 按课浏览、进度和得分（§7） |
| 计算页 | 正文 | 不限 | 按章 | 公式插件 | 参数和计算（§8） |
| 运行页、流程目录 | 正文、前 | — | — | 以后（§8） | 活书 |

**“最多 1”**：书里已经有一页目录时，再拖进一页目录，会提示“这本书已经有目录了，要替换吗？”。

### 3.1 封面

- **内容**：书名（就是书的名字）、副书名、作者（著、编、译，可以几位）、封面图（图片，D484）、一句简介。
- **页面**：照封面的样子排版显示；编辑时就是这些字段。
- **书的样子**：
  - 被 `![[书名]]` 引用、在资源列表里预览时，显示封面图、书名和作者；
  - 书的页面也显示它。
- 被引用时显示成什么样，是封面的职责；想换样子，就换一种封面。

### 3.2 版权页

- **内容**：书名、作者、出版者（可以是个人或单位）、版次和印次、发布记录、ISBN（可选）。
- **发布**（§6）在这里做：“发布新版”“重新印刷”；版本历史在这里看。
- **版本**：
  - 默认只有一种。
  - 课本可以设“学生版”“教师版”：在版权页里列出每种版本包含哪些角色的页。默认所有页都进两种版本，答案附录只进教师版。
- 没有版权页的书不能发布。第一次点“发布”时，自动加一页版权页。

### 3.3 前言、后记

- 普通的文字页（和正文页同一种写法），但**不编号**。
- 前言在“前面的部分”，后记在“后面的部分”，由它们选的种类决定：序、前言、致谢在前，后记在后。

### 3.4 正文页

专属于书的笔记，比普通笔记多三样：

1. **脚注**：`[^1]` 和 `[^1]: 注释的内容`。浏览时在这一页的末尾（以后可以由目录决定排成脚注还是尾注）。
2. **图、表、公式的题注**：
   - 写法：`![[电路图]]` 下面一行 `图：并联电路`，或者表格上面一行 `表：电阻值`。
   - 正文页把这些**告诉目录**（§5 的 `outline`），由目录编成“图 2-1”。
3. **索引词**：`{{索引:勾股定理}}`。阅读时不显示，由索引页收集。

- 拖出书外，正文页仍然是一篇能用的页，只是不再编号。
- 普通笔记放进书里也可以，只是没有上面三样。

### 3.5 附录

- 一个容器，像章一样，下面放正文页或任何资源。
- 编号方式由附录自己定：“附录 A”“附录 B”，里面的图编“图 A-1”。

### 3.6 参考文献

- **条目**：每条有作者、题名、出处、年份、类型（专著、期刊、网页……），按 GB/T 7714 的格式显示。
- **引注**：正文页里写 `[@张三2020]`。显示成什么样（“[3]”还是“（张三，2020）”），问参考文献页。
- **列表**：只列正文里引用过的，或者全部列出，由参考文献页自己设。

### 3.7 索引、图表目录

- **索引**：从全书各页收集索引词（§3.4），按拼音排序；每个词后面是出现的位置，点了跳过去。
- **图表目录**：从目录拿到全书图、表、公式的编号和题注，列出来。

## 4. 目录：浏览和编号

全书怎么读、怎么编号，都是目录的事。

### 4.1 浏览

目录页打开时，左边是目录树，右边是**浏览区**。书插件自带的目录有两种浏览方式，在目录页上切换，切换的结果是这一页的设置：

| 方式 | 样子 |
|---|---|
| **连续** | 从头到尾一页接一页往下滚，看得见的部分才加载（`sequence` 节点，§10） |
| **分页** | 一屏一页，“上一页”“下一页”，键盘左右键翻页；页码 `12 / 86` |

- 点目录里的任何一项，浏览区跳到那里。
- **阅读位置**：每个读者记住自己读到哪里，下次打开回到那里。
- 每一页标题旁有“打开”，在新标签页里打开那一页本身去编辑。

### 4.2 编号

- **目录汇总编号**：每种角色在接口里说明自己怎么编号（§5），目录按书里的位置把编号算出来。
  - 正文部分：按层级，层级名称默认“编、章、节”，更深的层用“1.2.3”；也可以选“1、1.1、1.1.1”或不编号。
  - 附录：按附录自己的方式（A、B、C）。
  - 前言、后记、封面等：不编号。
  - 图、表、公式：按章，“图 2-1”；附录里“图 A-1”。
- 编号**不写进任何页**；调整顺序后，编号自动跟着变。

### 4.3 交叉引用

- 正文页里写 `[[电路图]]`、`[[第三章的名字]]`，在书里显示成“图 2-1”“第三章”。
  - 被引用的东西在书里，显示编号；不在书里，照常显示名字。
- 显示什么，由正文页问目录（§5 的 `number`）。

### 4.4 子书

- 外层目录浏览到一本子书时，向子书的目录要它的目录项和编号。
- 子书**重新编号**，用它自己目录的设置；子书本身编“第一册”“第二册”，叫法在外层目录里设（默认“册”）。
- 文集、丛书、多卷书都是这样一层套一层。

### 4.5 被引用、导出

- `![[书名#第三章]]`：目录给出第三章的连续内容（不带目录栏）。
- `![[书名的目录]]`：目录页的嵌入，就是带编号的目录列表。
- **导出**：按目录的顺序和编号，把全书写成一个 Markdown 文件，图片放在旁边的文件夹（导出到授权文件夹）。
  - 导出是“按目录印一份”，所以由目录负责；
  - 书有几种版本时，导出前选导出哪一种（版本由版权页给出）。

### 4.6 别的目录

别的插件提供另一种目录，就换来一种读法：
- **课本目录**（练习插件，§7）：按课浏览，每课旁边是进度和得分。
- **幻灯目录**（以后）：一屏一页，全屏放映。
- **流程目录**（以后，§8）：从上到下一页页运行。
- **手册目录**（以后）：带搜索、只显示当前这一章。

## 5. 接口 `onedesk.book/1`

书插件定义这个接口。每种能放进书、又想担当角色的类型，由它的插件实现。下面是接口的动作，用 `host.interfaces.call` 调用：

| 动作 | 谁实现 | 谁调用 | 作用 |
|---|---|---|---|
| `roles` | 每个提供书页类型的插件 | 书、目录 | 返回 `[{ kind, role, part, numbering, single }]`：每种类型担当什么角色，在哪一部分，怎么编号，一本书里能有几页 |
| `outline` | 想被编号、被收集的类型（正文页、附录、练习页……） | 目录、索引、图表目录、参考文献 | 给出一页里面有什么：小标题、图表的题注、索引词、引注，以及它们的位置 |
| `number` | 目录 | 正文页（交叉引用）、图表目录 | 某一页或某个位置在这本书里的编号 |
| `entries` | 目录 | 外层书的目录（子书） | 这本书的目录项和编号 |
| `cite` | 参考文献 | 正文页 | 引注显示成什么 |
| `editions` | 版权页 | 目录（导出）、练习插件（公布） | 这本书有哪几种版本、每种包含哪些页 |

几条规矩：
- **只按角色找**：调用方先在书的子树里找到担当那个角色的页，再调用那个页的插件。从不写死某个插件的名字。
- **没实现接口的资源**：按正文、按章编号；`outline` 只取它的名字。
- **接口要定版本**：以后改不兼容就升到 `onedesk.book/2`。接口的修改由主会话决定，记进 decisions.md（硬性规则 10）。

## 6. 版本与发布（版权页）

- **发布新版**：版次加一；把整本书（按版权页定的版本）发布成文件。内核的 K9（§10）做实际的打包。
- **重新印刷**：内容没改、再发一遍时，印次加一。
- **读者那里**：导入后是书的**只读副本**，版权页显示“第 2 版第 1 次印刷 · 来自 某某”。作者改书不影响读者，直到读者导入新版。
- **一台电脑上**：作者和读者各用一个工作区，发布成文件、导入（`documents.md` §19.7 的流程不变）。以后接网络，换成订阅，文件格式不变。
- **学生版、教师版**：发布时选版本。学生版不含只进教师版的页（比如答案附录）。

## 7. 课本：练习插件加的角色

需求见 `documents.md` §19，仍然有效。按角色来分：

| 角色 | 带的逻辑 |
|---|---|
| **题**（资源） | 题干、空、判题规则、分值、提示、知识点；**答案、讲解**是“只进教师版”的字段（§10 的 K10） |
| **练习页** | 一节后面的“练一练”：几道题，书上直接做 |
| **测验页** | 一组题加上设置：答案什么时候给、能做几次、限时 |
| **作答**（资源，练习插件的树“作答”） | 学生做一次测验留下的：每题的答案、判定、得分、时间。**作答是练习插件自己的事，书不知道** |
| **答案附录** | 后面的部分；只进教师版。**公布答案**就是作者在答案附录里选“公布到第三单元”，然后重新印一次学生版：学生版里的答案附录多了已公布的那几个测验的答案，学生导入后自动判分 |
| **课本目录** | 按课浏览；每一课旁边显示进度和得分；“继续上次” |
| 成绩、错题本 | 练习插件的树“作答”里的两个页面，从作答里算 |

这样，**“老师公布答案”不需要任何特殊机制**：它就是答案附录进了学生版的新一次印刷。实体课本也是这样，答案在教师用书里，到时候才发给学生。

“交卷后”“每题答完”这两种马上就要判的方式，才需要把加密的答案提前发过去（K10 的指纹和密文，`documents.md` §21.2）。这两种只适合练习。

## 8. 活书：以后加的角色

- **计算页**（公式插件）：参数和计算，书里别的页可以引用它的结果。
- **运行页**：一个步骤，可以运行（HTTP、SQL、命令、AI……），结果传给后面的页，可以写期望（`@状态码 = 200`）。
- **流程目录**：一种目录。它的“浏览”就是从上到下一页页运行，有条件跳过、等人确认、失败就停，不做循环和跳转。跑一遍留下一份运行记录，可以导出成报告。

全部都是新的角色。书和书插件已有的角色都不用改。

## 13. 第②步详细设计：书和基本角色（已确认，已实现）

> 范围：book.md §11 第②步。做完后能用：文集、手册、带前言和附录的书，连续或分页阅读，编号，导出。
> 不在这一步：
> - 交叉引用、图表目录、参考文献、索引（第③步）。接口的 `number` 动作随交叉引用放到第③步。
> - 版权页和发布（第⑥步）。

### 13.1 这一步的角色和类型

都由书插件 `org.onedesk.book`（内置）提供。每种角色的代码各放一个文件（§0 第 2 条），书本身的文件里只有装订。

| 类型（短名） | 角色 | 部分 | 一本书里 | 编号 | 能放子节点 | 文件 |
|---|---|---|---|---|---|---|
| `book` 书 | 书（子书） | 正文 | 不限 | “第一册”（叫法由外层目录定） | 任何 | `book.js` |
| `cover` 封面 | 封面 | 不进阅读 | 最多 1 | 无 | 否 | `cover.js` |
| `toc` 目录 | 目录 | 不进阅读 | 最多 1 | 无 | 否 | `toc.js` |
| `preface` 前言 | 前言（序、前言、致谢） | 前 | 不限 | 无 | 否 | `text-page.js` |
| `afterword` 后记 | 后记 | 后 | 不限 | 无 | 否 | `text-page.js` |
| `page` 正文页 | 正文 | 正文 | 不限 | 按层级 | 否 | `text-page.js` |
| `appendix` 附录 | 附录 | 后 | 不限 | A、B、C | 任何 | `appendix.js` |
| 分组（内核） | 篇、章 | 正文（在附录里属于附录） | 不限 | 按层级 | 任何 | — |
| 其他任何资源 | 正文 | 正文 | 不限 | 按层级 | 照它自己 | — |

- **封面和目录不进阅读**：目录就是阅读本身；封面是打开书时看到的。
- 实体书的书名页和版权页合在第⑥步的版权页里。

### 13.2 书 `book`

| 项 | 内容 |
|---|---|
| 清单 | `tree: "resources"`，`page: "book"`，`draggable`，`accepts: ["*"]`，`embed: true`，`place: true`（§13.9 K-c），`defaults: {}`，没有字段 |
| 新建 | “新建 → 书”。保存后，书插件收到 `resource.changed`（`created`），在书下面建一页“封面”和一页“目录”（各自的 `newName`）。用户删掉它们也可以 |
| 页面 `book` | 封面给出的样子（§13.3），下面两个按钮：<br>• **开始阅读**：打开目录，从头开始；<br>• **继续阅读**：有阅读位置时才有，打开目录并回到上次的位置。<br>没有封面时显示书名；没有目录时，开始阅读按钮换成“加目录”。不放别的东西 |
| 装订（`place`） | 一页被拖进书、在书里拖动、在书里新建时，内核问书“它落在哪里”。书按这页的角色所在的部分（前、正文、后、不进阅读）把落点限制在那一部分之内：<br>• 封面、目录放在最前；<br>• 前言跟在它们后面，然后是正文；<br>• 附录、后记放在最后。<br>拖到别的部分里时，落到自己那一部分最靠近的位置。<br>“最多 1”的角色已经有了，再拖进来时提示“这本书已经有目录了”并拒绝（替换由用户先删再拖） |
| 嵌入 | `![[书名]]`：封面的样子。`![[书名#某一章]]`：交给目录（§13.4.6） |
| 代码 | 只有装订：角色表、`place`、新建时补两页、打开时把页面交给封面和目录 |

### 13.3 封面 `cover`

- **字段**：
  - 副书名（`text`）；
  - 作者（`text`，几位用顿号隔开，例：“鲁迅 著、张三 编”）；
  - 封面图（`attachment`，`accept: ["image"]`，D484）；
  - 简介（`longtext`）。
- **页面 `cover`**：一个表单，就是上面四个字段。书名就是外层书的名字，不在这里改，显示成只读的一行，旁边提示“书名就是书的名字”。
- **样子**：书插件里封面模块的一个函数 `face(书, 封面)`，返回：
  - 图片节点（有封面图时，宽度“中”）；
  - 一段 Markdown：`# 书名`、副书名、作者、简介。

  书的页面和 `![[书名]]` 都用它。以后换一种封面，换的就是这个函数。
- **没有封面时**：只显示书名。

### 13.4 目录 `toc`

#### 13.4.1 字段（目录的设置）

| 字段 | 类型 | 默认 | 说明 |
|---|---|---|---|
| 编号 `numbering` | `enum`：中文、数字、不编号 | 中文 | |
| 层级名称 `levels` | `text` | `章,节` | 用逗号分开，从书下面第一层开始。更深的层用“1.2.3” |
| 子书的叫法 `volume` | `text` | `册` | 子书编“第一册”“第二册” |

这三项显示在目录页顶上的一行（紧凑的表单行），不放在别处。

#### 13.4.2 页面 `toc`

```
┌ 目录 ─────────────────────────── [环境 ▾] │ 连续/分页  导出 ┐
│ 编号 [中文 ▾]  层级名称 [章,节]  子书的叫法 [册]               │
│ ┌ 目录栏 ─────────┐ ┌ 浏览区 ───────────────────────────────┐ │
│ │ 前言             │ │ 第一章  秒的认识                [打开] │ │
│ │ 第一章 秒的认识  │ │ （正文页的内容）                       │ │
│ │   第一节 …       │ │ 第一节  …                       [打开] │ │
│ │ 附录 A 换算表    │ │ …                                      │ │
│ └─────────────────┘ └───────────────────────────────────────┘ │
└──────────────────────────────────────────────────────────────┘
```
- **操作栏**：
  - “连续 / 分页”是切换按钮，存在页面的视图状态 `view.mode` 里（§6.5），页面里不再放同样作用的控件；
  - “导出”是一个动作（§13.4.7）。
- **浏览区**：一个 `sequence` 节点（§13.9 K-d），带目录栏。
- **书里还没有可读的页时**，浏览区显示：“把正文页、笔记或任何资源拖到这本书下面”。
- **目录不在书里**（被拖出来了）时，显示：“这页目录不在任何书里”。

#### 13.4.3 目录项怎么算出来（`entries`）

1. 用 K7 的 `host.resources.tree(书)` 按树的顺序读出书下面的全部节点。
2. 定每个节点的角色：
   - 书插件自己的类型，查 §13.1 的表；
   - 别的插件的类型，如果它的插件实现了 `onedesk.book/1`，问它的 `roles`（每次计算每个插件只问一次）；
   - 都不是，就是正文。
3. 跳过“不进阅读”的（封面、目录）。子书不往下展开节点，而是问子书的目录要它的目录项（§13.4.5）。
4. 按部分排：前 → 正文 → 后；同一部分内按树的顺序（装订已经保证了这个顺序，这里再排一次是为了保险）。
5. 编号（§13.4.4），得到每一项：
   ```js
   { key, resource, title, number, level, part, book? }
   ```
   - `title` 是“编号 + 空格 + 名字”；
   - `level` 从 1 开始，是在书里的深度；
   - 子书的书名项带 `book: true`。
6. 最多 20 000 项，多的截断，目录栏最后一项写“（还有 N 项未列出）”。

#### 13.4.4 编号的规则

**正文部分**：
- 按深度：书下面第一层是第 1 层。每个上级下面分别计数，分组、正文页、其他资源一起数。
- **中文**：第 n 层有层级名称时编“第一章”“第二节”；超过层级名称的层数，编成从第 1 层起的数字路径“2.1.3”。
- **数字**：一律“2”“2.1”“2.1.3”。
- **不编号**：只有名字。
- **子书**单独计数，不占章的号：“第一册”“第二册”。

**附录**：
- 附录自己编“附录 A”“附录 B”（中文和数字都这样，不编号时只有名字）；
- 附录里的东西编“A.1”“A.1.1”。

**前言、后记**：不编号。

**图、表**（第②步只做题注，交叉引用在第③步）：
- 正文页里的题注按**它所在的第 1 层**编号：“图 2-1”“表 2-3”。附录里“图 A-1”。不编号时“图 1”“图 2”全书连续。
- 同一个第 1 层里，前面各页有几张图，这一页从后面接着编。前面各页的图表个数用 `outline` 算（§13.6），并缓存（§13.4.8）。

#### 13.4.5 子书

- 外层目录遇到子书：
  1. 子书的书名项：`第一册 呐喊`，`book: true`，`level` 是它的深度；
  2. 找子书里的目录：
     - 是书插件的目录，直接算（同一个插件里的函数调用）；
     - 是别的插件的目录，调用那个插件的 `entries`；
     - 子书里没有目录，用外层的设置算子书。
  3. 子书的项全部接在书名项后面，`level` 加上子书的深度。
- 子书里**重新编号**。
- 子书再套子书，照样一层层算；最多 8 层，更深的只列书名项。

#### 13.4.6 浏览

- **连续**：`sequence` 的 `mode: "scroll"`。外壳只加载看得见的部分，前后各多加载 3 项。
- **分页**：`mode: "pages"`。一屏一项：
  - 子书的书名项、只有名字的分组，单独占一屏，显示成大标题；
  - 底部“上一页 / 下一页”和页码 `12 / 86`，键盘左右键翻页。
- **每一项**：
  - 有 `resource` 的，外壳用 `resource.embed` 显示它（带 `args`，§13.9 K-e）；
  - 这一项的标题由外壳画（带编号），嵌入里的 Markdown 标题下移到这一项的层级之下（最多到 6 级）。
  - 标题旁有“打开”，在新标签页打开那一页。
- **阅读位置**：
  - 外壳在浏览区停下 1 秒后，发页面事件 `{ id, type: "position", key }`；
  - 目录把它存进插件存储 `pos:<目录 id>`（一个工作区一个人用，所以不分人）；
  - 打开目录时，`sequence.start` 就是这个位置；书的页面上“继续阅读”也用它。
- **环境**：浏览区里各页的模板 `{{名字}}`，按目录这个标签页选的环境填。
- **被嵌入**：`![[书名#第二章名]]` 或 `![[书名#第二章]]`：
  1. 书把嵌入交给目录；
  2. 目录在目录项里找名字或编号相同的那一项；
  3. 返回那一项和它下面的全部，组成一个 `sequence`（不带目录栏，`mode: "scroll"`）。

  找不到时 `sectionMissing`。

#### 13.4.7 导出

导出是目录的动作 `export`（`output: "text"`），因为导出就是按目录的顺序印一份。

1. **没有授权文件夹时**，结果写“先授权一个文件夹”，附带“授权文件夹”按钮（结果区动作，调用 `host.files.addRoot()`）。
2. **写到第一个授权文件夹**（以后第⑥步按版本选）：
   - `书名.md`；
   - 图片放进 `书名-图片/`；
   - 同名已有时，自动加“ 2”“ 3”，不覆盖。
3. **文件内容**：
   - `# 书名`；
   - 封面：副书名、作者、简介；
   - 目录（带编号的列表）；
   - 然后每一项：
     - 标题按 `level` 写成 `##`、`###`……；
     - 正文是 `host.resources.embed(项, { args })` 的结果：
       - 文字照写；
       - 表格写成 Markdown 表格；
       - 图片用 `host.files.writeBlob` 写进图片文件夹，正文里写相对路径；
       - 链接写成名字。
4. **结果**：
   - 文件位置；
   - 结果区动作“在访达中显示”。

#### 13.4.8 缓存

- 图表计数要读各页的 `outline`。
- 目录把每页的 `outline` 结果按“资源 id + 版本号（`rev`，K7 的树里带）”缓存在插件存储里：
  - 版本号变了才重算；
  - 最多 5000 条，超出时清掉最早的一半。
- 不用事件，因为别的插件的资源改了，书插件收不到事件；版本号已经够用。

### 13.5 前言、后记、正文页（`text-page.js`）

三种类型共用一个页面 `text`，和笔记一样有“阅读 / 编辑”：
- 编辑：正文字段（`longtext`，`refs: true`）；
- 阅读：Markdown。

前言多一个字段 `variant`（序、前言、致谢），在信息面板里改，决定它在目录里显示的名字（名字为空时）。

**正文页比笔记多的两样**（也在前言、后记里生效）：

1. **脚注**：`正文[^1]`，加上单独一行 `[^1]: 注释`。阅读时：
   - 正文里变成上标的编号 ¹；
   - 这一页末尾列出“注释”；
   - 编号在这一页里从 1 开始。
2. **题注**：
   - 紧跟在一个嵌入（`![[…]]`）、图片或表格**下面**的一行 `图：说明`，或**上面**的一行 `表：说明`；
   - 阅读时变成“图 2-1　说明”（在书里，按 `args` 给的编号）或“图 1　说明”（单独打开时，这一页里从 1 编）；
   - 写法“图：”“表：”是正文页这个插件定义的（硬性规则 5），英文写 `Figure:`、`Table:`，日文写 `図：`、`表：`，三种都认。

**被嵌入**（`embed`）：
- 返回阅读时的 Markdown（脚注、题注都已处理）；
- 收到 `args.book` 时，用里面的编号前缀和起始序号编题注。

**拖出书外**：照常能用，题注按这一页自己编号。

### 13.6 接口 `onedesk.book/1`（第②步的三个动作）

书插件在清单里同时 `implements` 和 `uses` 这个接口。以后的练习插件等也这样做。

| 动作 | 输入 | 返回（`data`） |
|---|---|---|
| `roles` | `{}` | `{ kinds: [{ kind, role, part, single, container, numbering }] }`<br>• `role`：`cover`、`toc`、`preface`、`afterword`、`body`、`appendix`，或实现者自己定的名字（不认识的按 `body`）；<br>• `part`：`front`、`body`、`back`、`none`（不进阅读）；<br>• `single`：一本书里最多一页；<br>• `container`：下面的节点也进阅读；<br>• `numbering`：`level`（按层级）、`letter`（A、B、C）、`none` |
| `outline` | `{ resource }` | `{ headings: [{ text, level }], figures: [{ type: "figure"\|"table", caption }] }`，按出现的顺序。第③步再加 `terms`、`cites` 和位置 |
| `entries` | `{ resource: 目录 id, depth, settings? }` | `{ items: [{ key, resource?, title, number, level, part, book? }] }`<br>• `depth`：这本书在外层书里的深度；<br>• `settings`：外层的编号设置（子书没有目录时用） |

**怎么找到实现者**：
- `roles` 按插件调用：`interfaces.call("onedesk.book/1", "roles", {}, { plugin })`；
- `outline`、`entries` 按资源调用：`{ resource }`，由内核找到这种资源的插件（§13.9 K-f）。

**书插件调用自己的类型时**，不经过内核，直接调用同名的函数，但输入、返回和接口完全一样。所以别的插件的目录、正文页，和书插件自己的处在同等地位。

### 13.7 清单要点

```jsonc
"requires": { "resources": true, "contents": true, "files": true },
"uses": ["onedesk.book/1"],
"implements": { "onedesk.book/1": { "actions": ["roles", "outline", "entries"], "kinds": ["book", "cover", "toc", "preface", "afterword", "page", "appendix"] } },
"exports": { "actions": ["roles", "outline", "entries"] },
"contributes": {
  "kinds": [ /* §13.1 的七种 */ ],
  "pages": [ "book", "cover", "toc", "text", "appendix" ],
  "actions": [
    { "id": "export", "kinds": ["toc"], "output": "text" },
    { "id": "roles", "output": "none" }, { "id": "outline", "output": "none" }, { "id": "entries", "output": "none" }
  ],
  "events": ["resource.changed"],
  "menus": { "new": ["book", "page", "preface", "afterword", "appendix", "cover", "toc"] }
}
```

- 附录的页面 `appendix`：显示“附录 A　名字”和它下面各项的列表（可以点开）。编号要从目录算，所以附录页问书的目录。

### 13.9 内核：要加的通用能力

都不认识书（硬性规则 1）。每一项都改协议或清单，按硬性规则 10 记进 decisions.md。

| 编号 | 能力 | 内容 | 规则和限制 |
|---|---|---|---|
| K-a | 读子树 `host.resources.tree(id, { offset?, limit? })` | 按树的顺序（先父后子）列出下面的全部节点：`[{ id, name, kind, icon, depth, parent, rev }]` 和 `next` | 要 `requires.resources`；每次最多 2000 个；不含正文 |
| K-b | 读别的资源的嵌入内容 `host.resources.embed(id, { section?, args? })` | 返回和界面的 `resource.embed` 一样的东西 | 要新权限 `requires.contents`（“读取其他资源的内容”，安装时列出）；只读；用调用方所在标签页的环境 |
| K-c | 装订：清单 kind 的 `place: true` 和处理函数 `place(ctx, { node, before })` | 东西被拖进、移动到、新建在这种资源下面时，内核先问它落在哪里，返回 `{ before }`（或 `{ refuse: Label }`），然后**一次**写入 | 纯计算（只能读），1 秒内不返回就按用户拖的位置；必须有 `tree` |
| K-d | 视图节点 `sequence` | `{ type: "sequence", id, toc, mode: "scroll"\|"pages", start?, items: [{ key, title, level, resource?, args?, book? }] }`；外壳按需嵌入每一项 | 项最多 20 000；`level` 1–9；`title` ≤ 500 字；`args` ≤ 4 KB；可以出现在嵌入里（嵌入里的 `sequence` 不带目录栏），嵌套最多 3 层，已有的嵌入环检查照用 |
| K-e | 嵌入的参数 `args` | `resource.embed { id, section?, args? }` 把 `args` 交给 `embed(ctx, { section, args })` | 第③步“带参数的引用”（K3）的一部分，先做这一点 |
| K-f | 接口的两处扩展 | 1. `implements.<接口>.kinds`：几种类型都可以当锚点；`interfaces.call(…, { resource })` 按资源的类型找实现者。<br>2. `interfaces.call(…, { plugin })` 直接指定实现者。<br>3. **不在运行中也能调用**：在 `render`、`embed`、`place`、`children` 里调用时，对方以纯计算方式执行（只能读，写被拒 `pureCall`） | 调用深度 ≤ 4，不得成环（已有） |
| K-g | 写图片 `host.files.writeBlob(blob, path)` | 把一个存着的文件写到授权文件夹 | 要 `requires.files`；文件号必须被调用方能读的某个资源用到 |

## 14. 第②步的实际做法（和 §13 不同或补充的地方）

| 项 | 实际做法 | 为什么 |
|---|---|---|
| 编号的选项 | 字段 `numbering` 取 `words`（按层级名称）、`numbers`（1.1）、`none`；层级名称和子书的叫法留空时**按语言**取默认：中文“章,节”“册”，英文“Chapter, Section”“Volume”，日文“章,節”“巻”。中文、日文用“第一章”，英文用“Chapter 1” | 清单里的默认值是固定的，不能按语言变 |

| 封面怎么显示在书上 | 书的页面和 `![[书]]` 都是一个只有一项的 `sequence`：标题是书名，内容是封面的嵌入视图 | 封面图属于封面这个资源，界面只能为用到它的资源读图片；这样图片按封面读，书也不用懂封面 |
| 新建在书里的页 | 先问书落在哪里，建好后再移过去（两次写入） | 新建的写入命令没有位置参数；移动一次就够 |
| 题注 | 按出现的顺序编号，不检查是不是紧挨着图或表 | 简单可靠；写法照 §13.5 |
| 导出 | 写到第一个授权文件夹；没有授权文件夹时弹出选文件夹的对话框，提示“选好后再导出一次”。正文里的 `![[…]]` 照原样写出，不展开 | 运行中选文件夹的结果是异步到达的；展开嵌入留到以后 |

| `place` | 只对用户的操作（拖动、在书里新建）生效；插件自己的 `resources.create/move` 不经过它 | 插件不能在处理自己的事件时再被自己打断 |

## 15. 第③步详细设计：参考文献、索引、图表目录、交叉引用（已确认，已实现）

> 范围：book.md §11 第③步。做完后能用：学术书、规范文档、教材——正文里引用文献、引用别的章和图，书后有参考文献和索引，书前有图表目录。
> 不在这一步：
> - 公式编号“式（2-3）”，随第④步公式一起做；
> - 尾注（脚注仍在每页末尾）；
> - 参见条目（索引里的“见 ××”）。

### 15.1 这一步加的角色

都由书插件提供，每个角色一个文件（§0 第 2 条）。

| 类型（短名） | 角色 | 部分 | 一本书里 | 带的逻辑 | 文件 |
|---|---|---|---|---|---|
| `references` 参考文献 | 参考文献 | 后 | 最多 1 | 文献的著录格式（GB/T 7714）、引注怎么显示、列哪些 | `references.js` |
| `reference` 文献 | 一条文献 | 不进阅读（放在参考文献下面） | 不限 | 一条文献的字段 | `references.js` |
| `index` 索引 | 索引 | 后 | 最多 1 | 收集索引词、排序、列出位置 | `index.js` |
| `figures` 图表目录 | 图表目录 | 前（目录之后） | 最多 1 | 列出全书的图和表 | `figures.js` |

交叉引用不是一页，而是正文页的本事：正文页问目录“它在书里编第几”（§15.5）。

### 15.2 先问实体书

| 问题 | 实体书的做法 | 这里照做 |
|---|---|---|
| 引用文献怎么写 | GB/T 7714 两种体系：**顺序编码制**（正文 “[3]”，表按第一次引用的顺序编号）和**著者-出版年制**（正文 “（张三，2020）”，表按著者排序） | 两种都做，参考文献页上选，默认顺序编码制 |
| 一条文献怎么写 | 著者. 题名[文献类型标识]. 出版地: 出版者, 出版年: 引文页码. | 照 GB/T 7714 的格式拼出来 |
| 文献类型 | M 专著、J 期刊、C 论文集、D 学位论文、R 报告、S 标准、P 专利、N 报纸、EB/OL 网页、Z 其他 | 照用这些标识 |
| 索引怎么排 | 中文按拼音，同音按笔画；每条后面是页码 | 按拼音排（§15.8 的 K-j）；电子书没有页码，用**章节号**代替（“第二章 · 附录 A”），点了跳过去 |
| 图表目录 | 书前分“插图目录”“表格目录”，每行：编号、题注、页码 | 照做，页码换成章节号 |
| 交叉引用 | “见第三章”“如图 2-1 所示” | 写引用，显示成编号（§15.5） |

### 15.3 参考文献 `references` 和文献 `reference`

**一条文献是一个资源**（一切都是资源）：放在参考文献页下面。它的名字就是**引注名**，比如“张三2020”。

文献的字段（照 GB/T 7714）：

| 字段 | 说明 |
|---|---|
| 类型 `type` | M、J、C、D、R、S、P、N、EB/OL、Z（下拉，显示成“专著”“期刊”……） |
| 著者 `authors` | 几位用逗号分开；超过 3 位时，显示前 3 位加“等”（英文加 “et al.”），照规范 |
| 题名 `title` | |
| 出处 `container` | 期刊名、论文集名、报纸名 |
| 版本 `edition` | 第 1 版不写 |
| 出版地 `place`、出版者 `publisher` | |
| 年 `year`；卷 `volume`；期 `issue`；页码 `pages` | |
| 网址 `url`；引用日期 `accessed`；DOI `doi` | 网页要有网址和引用日期 |

- **文献的页面**：一个表单，就是上面这些字段；下面一行预览按规范拼好的样子。
- **被嵌入**：显示按规范拼好的那一行。

**参考文献页**：

| 设置 | 选项 |
|---|---|
| 体系 `system` | 顺序编码制（默认）、著者-出版年制 |
| 列出 `list` | 只列被引用过的（默认）、全部 |

- **页面**：上面一行是设置，下面是文献表。
  - 顺序编码制：按第一次被引用的顺序，“[1] 张三. 书名[M]. 北京: 某出版社, 2020.”；
  - 著者-出版年制：按著者排序（排法同索引）。
  - 下面单独列出**没找到的引注**（正文里写了，但没有这条文献），点了打开写它的那一页。
- **被嵌入、导出**：就是这张表。

**引注的写法**（正文页、前言、后记里；写法是书插件定义的，硬性规则 5）：

| 写法 | 顺序编码制 | 著者-出版年制 |
|---|---|---|
| `[@张三2020]` | [3] | （张三，2020） |
| `[@张三2020, 第 12 页]` | [3: 12] | （张三，2020：12） |
| `[@张三2020; @李四2019]` | [3, 5] | （张三，2020；李四，2019） |

- 引注名按名字找文献：先在这一页所在的书（或子书）的参考文献下面找，找不到再往外层书找。
- 英文界面的著者-出版年制用 “(Zhang, 2020)”。
- 不在书里时，引注照原样显示成 “[张三2020]”。

### 15.4 索引 `index`

**索引词的写法**（正文页里，阅读时不显示；书插件定义的写法）：

| 写法 | 意思 |
|---|---|
| `{{索引:勾股定理}}` | 索引词“勾股定理”，位置是这一页 |
| `{{索引:三角形/勾股定理}}` | 二级：主词“三角形”下的“勾股定理” |
| `{{index:…}}`、`{{索引:…}}`（日文） | 三种语言的写法都认 |

- 这种写法和模板 `{{名字}}` 不冲突：模板的名字里不能有冒号。
- **索引页**：
  - 按拼音排序（英文按字母）；
  - 每个词后面是出现的位置，写成编号（“第二章、第三章第一节、附录 A”），没有编号的写名字；
  - 一个词在同一页出现多次只算一次；
  - 点位置打开那一页。
  - 二级词缩进放在主词下面。
- **被嵌入、导出**：一张两列的表（词、位置）。

### 15.5 交叉引用（正文页的本事）

写法就是普通的引用 `[[名字]]`。这样内核照常记着它指向谁，改名也不会断（D321、D482）。

在书里阅读时，正文页把它显示成编号，仍然可以点：

| 引用的是 | 显示成 |
|---|---|
| 这本书里的一章、一节、一页、子书、附录 | 它的编号：“第三章”“第二节”“附录 A”“第一册”；没有编号的显示名字 |
| 一张嵌在正文里、下面有题注的图片（`![[电路图]]` 下一行 `图：…`） | “图 2-1” |
| 带题注的表格所在的那一页 | 那一页的编号（表本身不是资源，第一版不能单独引用） |
| 书外的东西 | 名字（照旧） |

**怎么做**：
1. 目录算目录项时，用 K-h（§15.8）读出每一页引用了谁；
2. 目录把“这一页的每个引用该显示成什么”放进这一项的 `args.book.labels`；
3. 正文页把它们交给文字节点的 `refLabels`（K-i），外壳照着显示。

- 单独打开一页（不在书里阅读）时，照旧显示名字。
- 别的插件想知道编号，调用接口 `number`（§15.7）。

### 15.6 图表目录 `figures`

- **位置**：在“前面的部分”，目录之后。
- **页面**：两张表，“插图”和“表格”。每行：编号、题注、在哪一章（点了打开那一页）。没有图或表的那张不显示。
- **被嵌入、导出**：同样两张表。
- **数据**：目录在算目录项时已经数过每一页的图和表（§13.4.4），现在把它们连同编号一起交出来（`entries` 的返回多了 `figures`，§15.7）。

### 15.7 接口 `onedesk.book/1` 的补充

都是加字段、加动作，原来的不变，所以接口仍是 `/1`。

| 动作 | 谁实现 | 补充 |
|---|---|---|
| `outline` | 正文页等 | 多返回 `cites: [{ keys, note }]`（引注，按出现的顺序）、`terms: [{ term, sub }]`（索引词）；`figures[]` 每项多一个 `of`（题注上面那个嵌入的名字，没有就不给） |
| `entries` | 目录 | 多返回：<br>• `figures: [{ type, number, caption, item }]`；<br>• `terms: [{ term, sub, item }]`；<br>• `cites: [{ keys, note, item }]`<br>（都按阅读顺序，`item` 是所在目录项的 `key`） |
| `number`（新） | 目录 | 输入 `{ resource: 目录, targets: [资源 id] }` → `{ labels: { id: "第三章" \| "图 2-1" } }`；不在书里的不给 |
| `cite`（新） | 参考文献 | 输入 `{ resource: 参考文献页, cites: [{ keys, note }] }` → `{ labels: ["[3]", "（张三，2020）", …] }`，和输入一一对应 |

**谁问谁**（都按角色找，不写死插件名）：
- 目录要给正文页准备引注的显示 → 问这本书的**参考文献**角色的 `cite`；
- 要准备交叉引用 → 自己算（编号本来就是目录的事）。
- 参考文献、索引、图表目录要全书的数据 → 问这本书的**目录**角色的 `entries`。
- 书里没有目录时，用书插件自带的算法。

### 15.8 内核要加的通用能力

都不认识书：

| 编号 | 能力 | 内容 | 规则 |
|---|---|---|---|
| K-h | 读一个资源引用了谁 `host.resources.refs(id)` | 返回 `[{ text, target: { id, name, kind } \| null, section }]`：正文里每个 `[[…]]`、`![[…]]` 现在指向谁（和信息面板里看到的一样） | 要 `requires.resources`；只读 |

## 16. 第③步的实际做法（和 §15 不同或补充的地方）

| 项 | 实际做法 | 为什么 |
|---|---|---|
| 按语言排序 K-j | 用 `icu_collator`，只在**工作进程**（`onedesk-worker`，应用里内核运行的地方）打开内核的 `collate` 功能；窗口外壳和开发用的 devhost 里的内核按“不分大小写的字符顺序”排 | 窗口外壳链接了内核：在那里加上 ICU 会让 Tauri 重新编译，而在 exFAT 盘上、带来源标记的进程写出的文件会多出 `._*`，让 Tauri 的编译脚本失败。只放在工作进程里，`pnpm start` 的窗口编译不变 |
| 引注的位置记录 | `outline` 的 `cites` 是 `[{ keys, notes }]`（每个引注名一个说明，没有为 `null`），不是 §15.7 写的 `{ keys, note }` | `[@a, 第 1 页; @b, 第 2 页]` 每条各有说明 |
| 交叉引用的标签 | 按引用写下的文字，**和**目标现在的名字都给一份 | 读者看到的正文里，引用已经换成目标现在的名字（D321） |
| 交叉引用显示的编号 | 用完整的编号：“第三章 第二节”“Chapter 3 Section 2” | 只写“第二节”分不清是哪一章的 |
| 著者-出版年制的著者 | 中文名照写；西文名取第一个词（GB/T 7714 西文姓在前：“Smith J”）；两位以上加“等”/“et al.” | 照规范 |
| 索引的位置 | 一行能打开一个地方：点一行打开这个词出现的第一页 | 表格一行只有一个目标 |
| 没找到的引注 | 正文里显示成 `[?名字]`（著者-出版年制 `（?名字）`），参考文献页单独列出 | 让作者一眼看到 |
| 引用数据的缓存 | 每页引用了谁按“资源 id + 版本号”缓存；目标的名字每次从书的树上取 | 目标改名时，引用它的那一页版本号不变 |

> 沿用 `embed-book.md` §20 的设计（D482 时写的、D484 定为保留），本节按 §0 的角色思路重新整理，并标出改动。

### 17.1 先问实体书

| 问题 | 实体书的做法 | 这里照做 |

| 公式在书里怎么出现 | 单独一行的公式，右边或下面标编号“（2-3）”，按章编号；正文里说“由式（2-3）可得” | 正文页里单独一行嵌入公式，下面一行写 `式：`（可以接说明），编成“式（2-3）”；交叉引用显示“式（2-3）” |
| 公式的符号说明 | 公式下面“式中：C——摄氏温度，℃” | 嵌入的公式下面列出参数的说明和单位 |
| 计算示例 | 例题：“已知 C = 37，求 F”，下面写出代入和结果 | 带参数的嵌入：`![[摄氏转华氏 \| C=37]]` 显示代入的值、中间结果和结果 |

### 17.2 角色和插件

| 谁 | 担当什么 | 带的逻辑 |
|---|---|---|
| **公式**（新插件 `org.onedesk.formula`，内置，类型 `formula`） | 一个能算的资源；放进书里时担当**计算页** | 解析和计算表达式、认出参数、格式化结果；被调用时给出结果 |
| **正文页**（书插件） | 正文 | 多认一种题注 `式：`，编成“式（2-3）” |
| **目录**（书插件） | 编号 | 按章给公式编号，和图、表一样；交叉引用的标签多了“式（2-3）” |
| **图表目录**（书插件） | 图表目录 | 多一张“公式”表 |

- 公式插件**实现接口 `onedesk.book/1`**，在 `roles` 里说：`formula` 的角色是 `calc`（计算页）、在正文、按层级编号、下面不再有东西。
- 这是第一个由**别的插件**提供的书的角色，书插件一行不用改。

### 17.3 公式插件 `org.onedesk.formula`

**写法**（插件自己解析，不执行任何代码）：
- 一行或几行，每行 `名字 = 表达式`；最后一行的名字是结果。
- 表达式里用到、但前面的行没有定义的名字，就是**参数**，不用另外“添加参数”。
- 数字：`37`、`-3.5`、`1.2e3`。
- 运算：`+ - * / ^ %` 和括号；乘除也认 `×`、`÷`。
- 函数：`abs round floor ceil min max sqrt pow exp ln log10 sin cos tan`；`round(x, n)` 保留 n 位小数。
- 常数：`pi`、`e`。
- 名字：字母、数字、下划线、汉字，不以数字开头。
- 限制：最长 4000 字、最多 50 行、括号和函数嵌套最多 32 层。
- 出错说明要看得懂：“缺少参数 C”““D” 不是数字”“第 2 行：除以零”“不认识 sqr，是不是 sqrt？”。

**资源里存什么**（`body`）：

| 键 | 内容 |
|---|---|
| `text` | 公式 |
| `unit` | 结果单位，如 “°F” |
| `decimals` | 小数位，默认 2；结果按它四舍五入，不加千分位 |
| `param.<名字>.label`、`param.<名字>.unit`、`param.<名字>.default` | 每个参数的说明、单位、默认值。默认值可以写 `{{环境参数}}`，跟着环境变 |

- 公式里删掉一个参数，它的说明等留着不显示；以后又用到同名参数时会回来。

**页面**：

```
┌ 摄氏转华氏 ─────────────────────── [环境 ▾] │ 保存 ┐
│ 公式                                                  │
│   F = C * 9 / 5 + 32                                   │
│ 结果单位 [°F]   小数位 [1]                              │
│ 参数（从公式里认出）                                    │
│   C   说明 [摄氏温度]  单位 [°C]  默认值 [20]           │
│ 试算   C [37]  →  F = 98.6 °F                          │
└──────────────────────────────────────────────────────┘
```

- **试算**：
  - 每个参数一个输入框，先填好默认值，改了立刻出结果，中间结果也列出；
  - 试算的值是页面的视图状态（`view.try.<名字>`，D467），不保存。
- **说明**写在信息面板里，AI 按说明可以写出公式（产品要求 6）。

**被调用时**（`embed`，参数由内核解析好交来，§17.4）：

| 写法 | 显示 |
|---|---|
| `![[摄氏转华氏]]` | 公式，下面“式中”列出参数的说明、单位、默认值 |
| `![[摄氏转华氏 \| C=37]]` | 公式，代入的值 `C = 37 °C`，中间结果，最后 `F = 98.6 °F` |
| `[[=摄氏转华氏 \| C=37]]` | 行内：`98.6 °F` |
| `[[=摄氏转华氏]]` | 行内：用默认值算出的结果 |
| 缺参数 | 用默认值；没有默认值时报“缺少参数 C” |
| 多给了不认识的参数 | 报“没有参数 X” |

**在书里**（担当计算页）：
- 公式直接放在书下面，就是一页，按层级编号（如“第三章 摄氏转华氏”）；
- 浏览时显示的就是 `![[摄氏转华氏]]` 的样子：公式和“式中”。

### 17.4 内核：带参数的引用（K3）

| 改动 | 说明 |
|---|---|
| 解析 | 引用里 `\|` 后面的参数（D482 已经能拆出来）：`名字=值`，逗号分开；值可以是数字、文字（含逗号或首尾空格时用双引号，`\"` 转义）、`{{环境参数}}`（可以夹在文字里）。`{{…}}` 按**显示它的标签页的环境**取值，取不到的保留原文。写错（缺 `=`、引号没收尾）时整个调用不算，结果是“参数写错了” |
| 交给插件 | 解析好的参数就是 `embed(ctx, { section, args, inline })` 的 `args`（名字 → 文字），和第②步书交来的 `args` 是同一个入口；`inline: true` 表示行内调用 |
| `resource.embed` | 加 `params?`（`\|` 后面的原文，外壳原样交来）、`inline?` |
| 行内的回答 | 只收 `{ text, error? }`：一行，最多 200 字 |
| `EmbedResult` | 加 `text?`、`error?`（行内结果），`args?`（解析并填好环境值的参数，显示“这次用的参数”） |
| `RefInfo` | 加 `call?`（是不是调用：`[[=…]]`，或带参数的 `![[…]]`）、`params?`（写下的参数）。信息面板里，调用标“调用”，后面是参数 |
| 没有嵌入视图的类型 | 块：仍是卡片；行内：没有结果，外壳显示成名字链接，标“不能计算” |
| 缓存 | 同一资源、同一版本、同一节、同样参数、同一环境、同一语言的结果放在内存里，最多 1000 条；资源改了就不用旧的，任何环境参数改了全部作废 |
| `host.resources.embed` | 也收 `params`、`inline`（导出时要把行内调用写成结果） |

### 17.5 外壳

- **行内调用** `[[=…]]`：
  - 画成**结果文字**，带细虚线下划线；
  - 鼠标停留显示“摄氏转华氏（C = 37）”，点击打开公式；
  - 还没算好时显示“…”；出错时标红，停留显示原因。
  - 一页的行内调用一起取（并发），全部回来再一次画好，不让文字一个个跳。
- **带参数的块**：嵌入块标题后面加上参数，如“摄氏转华氏（C = 37）”。
- **信息面板**：“引用”和“被引用”里，调用标“调用 C=37”。

### 17.6 书插件的改动（都在原来的角色里）

| 角色 | 改动 |
|---|---|
| 正文页 | 题注多一种：`式：说明`（`Equation:`、`式：`），说明可以空。显示成“式（2-3）　说明”（英文 “Equation (2-3) …”）。`outline` 的 `figures` 多一种 `type: "equation"` |
| 目录 | 公式和图、表一样按章计数编号；交叉引用 `[[摄氏转华氏]]`（它嵌在正文里、下面有 `式：`）显示“式（2-3）” |
| 图表目录 | 多一张“公式”表：编号、说明（没有说明就写公式名）、所在章 |
| 导出 | 行内调用写成结果，例如“98.6 °F”（用 `host.resources.embed` 的 `inline`） |

### 17.7 规则对照

| 规则 | 怎么满足 |
|---|---|
| §0.1 书只负责装订 | 书不变；计算页的角色由公式插件经接口声明 |

| 产品要求 | 公式是资源，有信息面板；跟着标签页的环境；参数只从公式里认出，没有第二个入口；不执行代码 |

## 18. 第④步的实际做法（和 §17 不同或补充的地方）

| 项 | 实际做法 | 为什么 |
|---|---|---|
| 参数交给插件 | 读好的参数和书交来的参数走同一个 `args`；公式插件不理会 `book` 这个键和不是文字的值 | 一个入口（§17.4） |
| 参数写错 | 结果里是 `badParams: true`，不调用插件；外壳写“参数写错了” | 内核不含界面文字 |
| 环境参数在笔记里 | 笔记在阅读时先把 `{{室温}}` 换成值，外壳看到的是 `C=25`；外壳按名字找回这个调用 | 笔记的模板照旧先填 |
| 交叉引用和调用 | 调用 `[[=…]]` 永远显示它算出的结果，不会被当成交叉引用显示成“式（1-1）” | 写调用就是要那个数 |
| 数字的舍入 | 四舍五入按“离零远的一边”（310.15 → 310.2），避开二进制小数的误差；去掉末尾的 0（77.0 → 77） | 和人手算一致 |
| 计算页里的计算页 | 公式放进书里，按层级编号；浏览时显示公式和“式中” | 照设计 |
| 测试用的程序 | 界面测试用本会话自己的编译目录里的 `onedesk-devhost` 和 `onedesk-worker` | 各个工作树共用仓库的 `target`，别的会话编译时会覆盖同名程序，测到的就是别人的代码 |

**测试**：内核 `crates/kernel/tests/subtree.rs`（调用一组）、`refs.rs` 的参数读取；公式插件 `plugins/org.onedesk.formula/main.test.ts`；书插件 `main.test.ts`（第④步一组）；外壳 `sequence-view.test.tsx`（调用的画法）；界面 `e2e/formula.spec.ts`。

### 19.2 插件和角色

### 19.3 题 `question`

**字段**：

| 字段 | 说明 |
|---|---|
| 题型 `type` | 填空（默认）、单选、多选、判断、问答 |
| 题干 `stem` | Markdown，可以有图片、公式（`![[…]]`、`[[=…]]`）。空写 `{{?}}`，一题可以几个空（练习插件定义的写法，和文书的填写项同一种） |
| 选项 `options` | 单选、多选用：一行一个，“A. 3”“B. 4”…… |
| 答案 `answers` | 一空一行；几个都对用 `\|` 隔开（`12÷3 \| 12/3`）；选择题写字母（`AC`）；判断题写“对”或“错” |
| 判题 `rule` | 按数值（默认）、按写法、按符号、老师批 |
| 分值 `points` | 默认 1；几个空平分 |
| 提示 `hint`、讲解 `explanation` | Markdown |
| 难度 `difficulty` | 1–5，可以不填 |
| 知识点 | 就用资源的**标签**（信息面板里填），不另设字段 |

**判题**（练习插件自己做）：

| 规则 | 怎么比 |
|---|---|
| 按数值 | 都当成数比：`0.5`、`1/2`、`½`、`.5` 相等；全角数字、首尾空格不算；带单位时只比数（`4 个` = `4`） |
| 按写法 | 去掉首尾空格、全角换半角后，字字相同 |
| 按符号 | `>` `<` `=` `≥` `≤`，全角半角都认 |
| 老师批 | 不自动判，交卷后显示“待批”；在作答页上点“对”“错”打分（这一步作者和学生在同一个工作区） |
| 选择题 | 选中的字母相同；多选题选对一部分得一半分（在测验设置里打开） |
| 判断题 | “对、√、T、是”和“错、×、F、否”都认 |

**页面**：
- 上面是字段；下面是“**学生看到的样子**”的预览，可以直接**试做**：填了点“检查”，显示对错。试做不留作答。

**快速出题**：
- 在练习页、测验页上，“快速出题”框里一行一题：`3 + 5 = (8)`、`7 × (8) = 56`、`38 (<) 83`；
- 括号里的就是答案，括号换成空。
- 数字按数值判，符号按符号判。
- 点“生成”，一次建好一批题，放在这一页下面。

### 19.6 练习页 `practice`：书上直接做（K11）

### 19.8 成绩单 `grades`、错题本 `mistakes`

**第一次交卷时**，“学习记录”树里自动建好一份成绩单、一份错题本（之后不再自动建）。

**成绩单**：
- 按书、按测验：做了几次、最高、最后、满分、最近一次的日期；点一行打开那次作答。
- 按知识点（题的标签）：做过几题、对了几题、正确率，从低到高排。

**错题本**：
- 列出做错过、而且之后没再做对的题：题干（前一行）、出自哪个测验或练习、错了几次、最近一次；
- 按知识点、按书分组；
- 点一行打开那道题；
- 操作栏“**再练一次**”：把这些题当一次新的作答来做；再练做对的，从错题本里拿掉（历史还在作答里）。

### 19.9 内核：可交互的嵌入（K11）

都不认识题：

| 改动 | 说明 |
|---|---|
| 嵌入里可以有表单 | `embed` 的回答可以有 `form` 节点。字段**不绑定**任何资源（不写 `bind`），值只在外壳里，属于这一处嵌入 |
| 嵌入的按钮 | 回答里可以有 `actions: [{ id, label, icon? }]`（最多 4 个），外壳画在嵌入的下面 |
| 新协议 `resource.embedAct` | `{ id, section?, params?, args?, envId?, locale?, action, values }`：用户点了按钮。内核调用这种类型的 `embedAct(ctx, { section, args, action, values })`，回答 `{ view?, actions?, message? }`：新的样子（同样检查）、按钮、提示 |
| 权限 | `embedAct` 是用户的操作：插件可以写**自己的**资源（作答），和页面事件一样记进审计；不能写嵌入它的那个资源；AI 不能调用 |
| 清单 | 声明了 `embed: true` 的类型可以注册 `embedAct`，不另设开关 |

**外壳**：
- 嵌入里的表单照常画（输入框、选项……），值记在这一处嵌入里；
- 按钮画在下面；
- 点了就发 `resource.embedAct`，用回答替换这一处的样子；有 `message` 时弹出提示。

**公式也用上它**（第④步留下的）：书里的公式下面多一行参数输入框和“算”按钮，读者改了参数马上看到结果，不保存。

### 19.10 课本目录 `lessons`：另一种目录

- 担当目录的角色：一本书里有它，就不能再有书插件的目录（装订的规矩，已有）。
- 浏览和书插件的目录一样（连续、分页、阅读位置）。
- **编号不自己算**：调用书插件的 `entries`（按书调用，书插件补上这一种调用：`{ book }`），拿到带编号的目录项。
- 在每一项上加上**进度**：
  - 练习页：“✓ 全对”“3/5”；
  - 测验页：“85 分”“未做”。
- 写在目录栏的标题后面。
- 书的页面上“继续阅读”同样回到上次的位置。

这是 §0 第 3 条的例子：换一种目录，就换来按课学习的读法，书插件一行不用改（只补了按书调用 `entries`）。

### 19.11 给 AI

- 题和测验：给题干、答案、讲解（这一步没有密封）。
- 作答、成绩单、错题本：给学生自己的答案和对错；AI 可以按错题出类似的题，“应用”后成为新的题。

### 19.12 测试（全部通过后才提交）

**内核**：
- 嵌入里的表单和按钮的检查（字段不能有 `bind`，按钮最多 4 个）；
- `resource.embedAct`：转给插件、写自己的资源、不能写别人的、审计、AI 不能调用。

**练习插件**：
- 判题：按数值（分数、小数、全角、带单位）、按写法、按符号、选择（多选部分分）、判断、老师批；

- 练习页的检查和重做（同一份作答）；
- 测验：开始、作答、交卷、计分、限时、次数、交卷前能不能改、每题答完；
- 作答的快照；
- 成绩单（按测验、按知识点）、错题本（收集、拿掉、再练一次）；

**书插件**：`entries` 按书调用。

**外壳**：嵌入里的表单、按钮、替换样子、提示；公式在书里试算。

**界面**（真内核，从“新建”开始）：
1. 新建书“数学三年级”，加一页课本目录（替换原来的目录）；

## 20. 第⑤步的实际做法（和 §19 不同或补充的地方）

| 项 | 实际做法 | 为什么 |

| 从别处引用题 | 测验页上一个“引用别处的题”的选择框，选好后点“加入这道题”；题留在原处 | 内核对“类型接受的东西”一律是移动（D390）；测验接受题，所以拖进去是把题挪进来，不是引用 |

| 打开书 | 书插件找“担当目录角色”的那一页（自己的目录，或课本目录），“开始阅读”打开它 | §0：只按角色找 |

## 21. 第⑥步详细设计：版权页（发布、版次印次、只读副本、学生版和教师版、答案附录和公布）（待确认）

> 范围：book.md §11 第⑥步，`documents.md` §19.6、§19.7 的需求。做完后能用（一台电脑、两个工作区）：
> 1. 老师在“老师”工作区写好课本，在版权页上点“发布”，得到一个书的文件；
> 2. 学生在“学生”工作区导入，得到只读的课本，做练习、做测验；
> 3. 老师改课本不影响学生，出新版后学生更新，作答和错题都还在；
> 4. 老师在答案附录里选好要公布的测验，点“公布”，再印一次学生版；学生导入后自动判分。
>
> 不在这一步：网络订阅和自动更新、交回作答、全班成绩、正式考试（判题在老师那边）。

### 21.1 先问实体书

| 实体书 | 这里 |
|---|---|
| 版权页：书名、著者、出版者、**版次和印次**、书号 | 版权页这一页：这些字段，加上发布记录 |
| 内容改了出**新版**；只是再印一批是**新印次** | “发布新版”版次加一；“重新印刷”印次加一，内容就是那一版的 |
| 学生用书、**教师用书**（多了答案和教学说明） | 一次发布分出**学生版**和**教师版**两个文件 |
| 课本后的**习题答案**只在教师用书里，到时候发给学生 | **答案附录**只进教师版；“公布”时，学生版重新印一次，带上已公布的那几个测验的答案 |
| 书发出去，读者手里的书改不了 | 学生那里是**只读副本** |
| 再版后，旧书照样能看，学生的作业本还在 | 更新到新版时，作答、成绩、错题都不受影响 |

### 21.2 角色

| 角色 | 由谁提供 | 带的逻辑 |
|---|---|---|
| **版权页** `colophon`（新） | 书插件 | 版次、印次、出版信息；**发布**、**重新印刷**；发布记录；学生版和教师版各包含哪些页 |
| **答案附录** `answers`（新） | 练习插件 | 在后面的部分，编 A、B、C；**只进教师版**；列出全书的答案和讲解；选哪些测验公布，点“公布” |
| 题 | 练习插件 | 答案和讲解是“**保留字段**”（§21.5）；在学生那里没有答案时，作答“等公布” |
| 目录（导出） | 书插件 | 导出时选学生版或教师版 |

- 角色表（接口 `roles`）多一个可选属性 `edition`：`"teacher"` 表示只进教师版。答案附录这样声明，书插件只认这个属性，不认识“答案”。
- 版权页在“前面的部分”，最多一页。没有版权页的书不能发布；在书里“新建 → 版权页”就有了。

### 21.3 版权页 `colophon`

**字段**：出版者、书号（可选）、版本说明（可选）、**分不分学生版和教师版**（默认：分）。书名就是书的名字，著者取封面上的。

**页面**：
```
┌ 版权页 ─────────────────────────────────── │ 发布新版  重新印刷  保存 ┐
│ 数学三年级（上）                                                       │
│ 著者：张三　出版者：某学校数学组　书号：（无）                          │
│ 当前：第 2 版第 3 次印刷                                                │
│ 分学生版和教师版 [是]                                                   │
│ 发布记录                                                                │
│   版次  印次  版本    时间              文件                     公布到 │
│   2     3     学生版  2026-11-26 10:20  数学三年级-2.3-学生版.odpack  第一单元测验 │
│   2     3     教师版  2026-11-26 10:20  数学三年级-2.3-教师版.odpack  —     │
│   …                                                                     │
└────────────────────────────────────────────────────────────────────────┘
```

- **发布新版**（一个运行）：
  1. 版次加一、印次回到 1；
  2. 内核把这一版的书**存一份**在老师的工作区里（不能改，§21.4）；
  3. 写出两个文件（学生版、教师版）到第一个授权文件夹；
  4. 结果给出文件位置，可以“在访达中显示”。
- **重新印刷**：
  - 用**那一版存下的内容**，印次加一，再写出文件；
  - 老师已经接着改了原书也不要紧，印出来的仍是那一版；
  - 发布记录里每一版都能“重印”，给还在用旧版的学生公布答案就用它。
- **发布记录**：每次一行；点一行在访达中显示那个文件。
- 接口：版权页实现 `print({ edition?, variant })`（重印某一版），答案附录“公布”时调用它（§21.6）。

### 21.4 内核：发布与只读副本（K9）

都不认识书，只认识“一棵子树”：

| 能力 | 说明 |
|---|---|
| `host.packages.publish(root, { edition, printing, variant, exclude, path })` | 把 `root` 下面的整棵子树（加上用到的图片）写成一个**资源包文件**（`.odpack`）到授权文件夹。`exclude`：这一版不带的资源（教师版专用的页）。保留字段按 §21.5 处理。包里记着：发布人（老师工作区的编号）、根、版次、印次、版本（`student` / `teacher`）、时间。要 `requires.files` |
| 这一版的存档 | `edition` 第一次发布时，内核把子树原样存进工作区的 `packages/` 文件夹，之后的重印都从这里出；存档不能改，资源被删了也还在 |
| `host.packages.reprint(root, { edition, printing, variant, exclude, reveal, path })` | 用存档重印；`reveal`：这一次可以带出原文的保留字段（资源 → 字段） |
| `package.inspect` / `package.import`（用户操作，外壳调用） | 先看包里是什么（书名、发布人、版次印次、版本、是第一次导入还是更新），用户确认后导入 |
| 只读副本 | 导入的资源**编号不变**，`origin` 是 `subscribed`，`origin_ref` 是包的根。用户和插件都不能改、不能删其中一部分、不能往里面加东西，也不能把它们拖出去（`denied/readOnlyCopy`）；整本可以删 |
| 更新 | 同一个发布人、同一个根、更新的版次或印次：内容整体换成新的；包里没有了的资源删掉；工作区里别处引用它们的东西（作答、错题）不受影响（作答里本来就存着题的样子，第⑤步） |
| 不能导入自己发布的 | 发布人是自己时拒绝（编号会撞） |
| 记录 | 新表 `copies`（根、发布人、版次、印次、版本、导入时间），新迁移 `0017_copies.sql`，带升级测试（硬性规则 6） |

**包的格式**：一个 zip 文件（只存不压缩），里面一个 `package.json`（资源和版本信息）和 `blobs/`（用到的图片）。读写都在内核里做，用一个很小的 zip 读写器（和主进程解 `.odplugin` 的规矩一样严格：只认存储和 deflate，不认加密）。

**外壳**：
- 命令面板和“新建”菜单旁有“**导入资源包**”：选文件 → 显示包的信息 → 确认导入；
- 只读副本在树上标“只读”，信息面板显示“只读 · 来自 某某 · 第 2 版第 3 次印刷（学生版）”；
- 只读副本的页面全部只读（`Resource.readOnly`，外壳已有）。

### 21.5 保留字段和“当场判”（K10）

| 改动 | 说明 |
|---|---|
| 清单 | 字段可以声明 `withheld: true`（保留字段）：教师版照常带；**学生版不带**，除非这一次 `reveal` 了它 |
| 指纹（当场判用） | 类型可以注册 `seal(ctx)`：发布学生版时，内核问它“这个资源的保留字段要不要带指纹”，它返回 `{ checks: { 字段: [可接受的写法…] } }`（由插件先规范化，比如 `1/2` → `0.5`）。内核把每个写法加盐取哈希放进包里 |
| 原文放钥匙串 | 有指纹的字段，原文也随包带上；导入时内核把原文存进**学生工作区的钥匙串**（硬性规则 7），数据库里只有指纹 |
| `host.sealed.check(资源, 字段, 写法)` | 学生那里：用指纹判断一个（规范化过的）写法对不对 |
| `host.sealed.open(资源, 字段)` | 学生那里：从钥匙串取原文；插件只在作者定的时机调用（每题答完、交卷后） |
| 已公布 | 重印时 `reveal` 了的字段，原文直接带上，和教师版一样，不需要指纹和钥匙串 |

**练习插件怎么用**：
- 题的 `answers`、`explanation` 声明为保留字段。
- `seal`：一道题如果在**练习页**里，或在“交卷后”“每题答完”的**测验**里，就给出每空可接受的写法（按判题规则规范化）；只在“老师公布”测验里的题，不给（学生那里什么都没有，最安全）。
- 判题：有原文按原文判；没有原文但有指纹，用 `sealed.check` 判；两样都没有，这题“**等公布**”。
- 答案和讲解：到了时机，用 `sealed.open` 取来显示。

**保密程度**（要说清楚）：
- “老师公布”的测验：学生那里事先**什么都没有**，最安全。
- 练习和其他测验：指纹能被挨个试（`3 + 5` 这种很快就试出来），钥匙串里的原文懂技术的人能取出。**只适合练习**；正式考试要等网络，由老师那边判。

### 21.6 答案附录 `answers` 和“公布”

**答案附录**（练习插件提供，只进教师版）：
```
附录 A　习题答案
  第一章 练一练          1. 8　2. 8　3. <
  第二章 单元测验  [√ 公布]   1. 8　2. （问答）参考：……　讲解：……
                                              [公布]（运行）
```
- 按目录的顺序列出书里每个练习页、测验页的答案和讲解。
- 每个测验旁边一个勾“公布”。
- 第一版增加一种答案时机“**老师公布**”（测验的默认），学生版里不带它的答案。

**公布**（答案附录的运行动作）：
1. 记下勾选了哪些测验；
2. 通过接口调用这本书版权页的 `print`：用当前这一版重印学生版，`reveal` 这些测验里所有题的 `answers`、`explanation`；
3. 学生导入这次印刷后：
   - 这些题有了答案原文；
   - 练习插件收到这些题更新了的事件，把“等公布”的作答**重新判分**，进成绩单和错题本。

**给还在用旧版的学生公布**：在版权页的发布记录里那一版上点“重印”。

### 21.7 学生那边的样子

- 资源树：`📖 数学三年级（上）🔒`，下面的一切都只读。
- 书照常读（目录或课本目录），练习照常在书上做（判得了的当场判，判不了的显示“等公布”）。
- 测验照常开始、交卷；“老师公布”的测验交卷后显示“已交卷，等老师公布答案”。
- 学习记录、成绩单、错题本都在学生自己的工作区里，不受更新影响。
